# Godot Pilot Resource Provenance

This file is the initial resource and dependency allowlist for the desktop-only Godot pilot. An absent component is forbidden. Adding or replacing an engine binary, binding, font, material source, shader source, or plugin requires an approved change, a complete provenance row, and a passing `GodotResourceLicenses` audit before distribution.
