# Bounded corpus dispatch slices

This file narrows the family matrices in [record packets](02-records.md), [aggregate packets](03-aggregates.md) and [region packets](01-evidence.md) into the actual worker assignments. The [corpus contract](00-corpus-contract.md) is binding in every slice. A worker edits only the stated family producer/Rust module (plus an explicitly named exporter test); the controller alone edits `inventory.go`, `discover.go`, shared Rust dispatcher, `contracts.json`, tracked assets, task status and ledger. Every slice starts with a Go-produced external `selection.json`, has at least one substantive red case or missing route, and ends with nonzero Go discovery, reviewed integration, nonzero Rust execution, complete runtime-oracle package, derived Rust manifest consumers, audit, then a scoped commit. Comparator-sensitivity mutations deliberately mismatch input and expected values **only in transient in-memory test copies**; they never enter an accepted candidate or manifest. Refresh that family's `Family.Sources` hashes on each slice because its producer file changes; preserve the old equal source-revision fields until 5.1. Every rollback shorthand below means: revert that slice's Go producer and Rust module changes, its exact controller-owned route/cases/assets/dispatcher edits, and the matching family source SHA, while retaining earlier accepted slices; a rollback that cannot preserve the prior manifest is incomplete. Do not make two slices that edit the same producer concurrently. If a failing parity case implicates a read-only production codec, return the input, Go/Rust outcome and bytes to the controller to revise scope; do not change it silently.

## Node 1.4a — region committed-bank order

**Prerequisite:** 1.3. **Editable:** `packages/tools/cmd/runtime-oracle/storage_region_test.go`, `packages/engine/crates/mornlea_storage/tests/storage_corpus/region.rs`. **Deliverable:** register and execute `save.region/1/order` with both committed generations, one corrupt bank fallback, two standby banks, equal identical A preference and equal divergent rejection. Go produces two 28,672-byte banks, decodes each with the same signed key and `file_size`, then calls `SelectRegionBank`; Rust mirrors `decode_region_bank` and `select_region_bank`. Include an occupied zero-length payload and sector-16 last slot with `file_size` large enough for its extent. A `component:"banks"` input must be exactly 57,344 bytes; a missing half fails selection validation before export. Baseline red is the absent `order` route. **Gate:** Go `^TestStorageRegionOrder`, then controller integration, nonempty Rust `region_order_`, full Go oracle and Rust derived consumers. **Commit:** `test(storage): execute region bank order`. **Rollback:** this order route/cases/assets only.
