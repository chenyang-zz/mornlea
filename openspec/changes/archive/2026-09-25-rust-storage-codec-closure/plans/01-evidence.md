# Evidence foundation and region packets

The [frozen corpus contract](00-corpus-contract.md) is a prerequisite interface for every node here. Implementation starts from the accepted safety SHA, with `make rust` before focused Go commands on a clean checkout. Read root, engine/tests, storage, tools/runtime-oracle and Go region guides, then preserve unrelated worktree edits. Shared manifest, registry, discovery and Rust loader files are controller-serialized. Family workers own only the exact files named below. No producer writes a tracked fixture or corpus asset; no Rust test treats zero selected cases as success.

<a id="node-1-1"></a>
## Node 1.1 — validate and transfer one storage selection

**Prerequisite:** accepted `rust-storage-safety-repairs`. **Editable:** `packages/tools/cmd/runtime-oracle/inventory.go`, `discover.go`, new `storage_manifest_test.go`, `runner_helpers_test.go` only to add fixed storage producer IDs to its closed table, `packages/audit/dependency_test.go` only to permit test-only `server/storage/storagedef`, and `packages/audit/AGENTS.md` for that exact boundary. **Read-only:** `contracts.json`, all production Go storage packages, Rust storage source. **Deliverable:** candidate selection parsing, exact per-family argument validation and safe external merge without any claimed `save.*` route or copied tracked asset. Production runtime-oracle imports remain stdlib-only.

**Exact interface:** add `Arguments json.RawMessage` with JSON key `arguments,omitempty` to `CaseSpec`. Define test-only `StorageSelection { ProducerID string; Cases []CaseSpec; Sources []SourceSpec; Routes []ConsumerRoute }` with JSON keys from the corpus contract, plus `readStorageSelection(candidateDir string) (StorageSelection,error)` and `mergeStorageSelections(root string, base Inventory, selections ...StorageSelection) (Inventory,error)`. `read` validates absolute external realpath, strict `selection.json` keys/duplicate JSON keys, `CaseSpec` arguments/paths/hash/size against files in that candidate directory, and source SHA against the checkout before returning. `merge` clones `base`, appends only reviewed save cases and exact routes, updates only named family `Sources/Cases`, sorts those lists and rejects duplicate/conflicting IDs, missing source file/hash, unknown version/route, unregistered producer and changed unrelated family. It does **not** call `ReconcileWorking` while candidate assets are still external. The controller calls `ReconcileWorking` only after reviewed assets are copied into the repository and exact routes are registered. A temporary in-memory registry may hold candidate routes for pre-integration structure validation; the production registry receives a route only when a matching Rust test exists in node 1.3 or later.

**Red/green tests:** wrong/missing player ID; chunk revision as JSON number; region order missing second bank, wrong component or file size type; unknown argument key; `capacity` on decode; missing checkpoint or `["0","1"]`; stale source hash; duplicate ID; asset path escape, symlinked ancestor, repo-contained export root; conflicting family source; missing producer ID; unknown route; unrelated family changed. A test-only import of `storagedef` must pass the audit, while the same import in runtime-oracle production source must fail the audit. Start with a compilable malformed-argument test against the existing `CaseSpec`/validator and show it is accepted or dropped on baseline; then add the interface and parser. With export unset, no directory is created. `go test ./packages/tools/cmd/runtime-oracle -run '^TestStorageSelection' -count=1` lists nonzero tests, fails red, passes green. Run full runtime-oracle package and `go test ./packages/audit -run '^TestRuntimeOracleInternalDependencies$' -count=1`; do not loosen any other audit route. **Commit:** `test(storage): define source-bound save selections`. **Rollback:** this infrastructure commit only; no manifest mutation.

## Node 1.3 — first real region route

**Prerequisite:** 1.2. **Editable worker files:** new `packages/tools/cmd/runtime-oracle/storage_region_test.go`, new Rust `packages/engine/crates/mornlea_storage/tests/storage_corpus/region.rs`; **controller-only files:** Go `inventory.go`, `discover.go`, `contracts.json`, reviewed case assets, Rust dispatcher module registration. **Read-only:** Go/Rust production region codecs and committed region fixtures. **Deliverable:** at least one Go-produced v1 bank/superblock decode and one encode case executed by Rust through nonempty routes.

**Seed:** signed `RegionKey {dimension:-3,x:-1,z:2}`; all-empty standby generation 0 and committed generation 1, plus entry 0 at sector 15 with sector count 1, payload length 0, revision 1 and CRC 0. Use `file_size=65536` for the occupied entry, because its one-sector extent ends at sector 16; the empty bank may use 61,440. Go `EncodeSuperblock`, `EncodeRegionBank`, `DecodeSuperblock` and `DecodeRegionBank` produce raw input, exact 4,096/28,672 encode assets and the complete `StorageValueV1` digest. Rust calls `decode_superblock`, `decode_region_bank(key,bytes,file_size)`, `encode_superblock_into` and `encode_region_bank_into`. Register `save.region/1/decode` and `save.region/1/encode` only after both module tests execute. The encode case decodes its bank input before writing. Baseline red: no registered storage route and no real region case; malformed candidate hashes fail before integration.

**Handoff:** worker runs `go test ./packages/tools/cmd/runtime-oracle -run '^TestStorageRegion' -count=1` with a fresh external export root and gives the controller its `selection.json` path and source/asset digests. Controller verifies it, adds `storage_region_test.go` to `Discover` sources, registers exact routes, exclusively copies assets, **preserves the current equal source-revision values** and runs Go reconciliation. Only **after** this integration does the Rust `region_` test have a nonzero case set. Run `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_storage --test storage_corpus --locked region_ -- --list` and without `-- --list`, full Go runtime-oracle race, Rust downstream corpus consumers, and Go audit. **Commit:** `test(storage): execute region corpus seed`. **Rollback:** controller restores the pre-node registry/manifest/assets; no region production change.

## Node 1.4 — region selection and corruption

**Prerequisite:** 1.3. **Editable worker files:** Go `storage_region_test.go`, Rust `tests/storage_corpus/region.rs`. **Controller-only:** route `save.region/1/order`, `Discover` source hash, manifest/assets. **Read-only:** Rust `src/region.rs`, Go `region_format.go` and existing tests. A newly proved codec defect requires the controller to revise this packet before changing those production files.

**Cases:** signed key and last slot at sector 16; occupied payload length 0; one invalid bank falling back to the other; both standby banks rejected; equal generation identical chooses A; same generation unequal content rejects; offset 14, overlap, u32 sector-end overflow, payload >1 MiB, extent beyond 61,440-byte file, nonzero reserved padding, wrong magic/version/key/checksum. For bank selection use `operation:"order"`, `component:"banks"` and exactly 57,344 bytes `bankA||bankB`; Go calls `SelectRegionBank` with the two actual decode results, Rust calls `select_region_bank` likewise. Reseal CRC for semantic corruption so the intended field is reached. Compare exact bytes on encode and the full selected bank digest/index on order. Flip one selected entry in the expected digest while keeping source/input hashes and require Rust mismatch.

**Validation:** fresh external Go producer, controller review/integration first, then nonempty `region_` Rust test; also `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_storage --test runtime_contract --locked region_`, full Go runtime-oracle and downstream Rust manifest consumers. The producer with a missing bank body or a `component:"bank"` order row fails before export. **Commit:** `test(storage): close region selection corpus`. **Rollback:** controller reverts only new order route/cases/assets; prior seed remains valid.
