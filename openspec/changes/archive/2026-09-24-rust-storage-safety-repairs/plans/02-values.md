# Current-value packets

These nodes keep public save DTO layouts stable. A storage DTO is not a validated gameplay value; the four exact checked conversion functions in `design.md` are the only planned additions. They return `StorageError::Corrupt` for invalid source values and do not rewrite them. Nodes 3.1–3.3 are source-of-rule refactors: existing valid/invalid behavior may already agree with the domain, so the initial compile failure of a new checked API is an acceptable red signal **only together with** its substantive boundary matrix and the duplicate-rule source audit named below. A worker must not report a newly named function alone as acceptance. The existing Rust `runtime_contract.rs` and `packages/engine/tests/runtime_corpus.rs` are downstream consumers and run after each export change. The controller serializes `src/lib.rs` edits. Go format packages are read-only.

## Node 3.1 — shared identity rule

**Prerequisite:** 2.2 for serial crate integration. **Editable:** `src/identity.rs`, `src/lib.rs`, new `tests/safety_domain_values.rs` identity section. **Read-only:** `mornlea_domain/src/identity.rs`, Go `packages/shared/core/player_id.go`. **Produce:** `checked_player_id(PlayerId)->StorageResult<mornlea_domain::PlayerId>` and `checked_companion_id(PlayerId)->StorageResult<mornlea_domain::CompanionId>`.

**Cases:** for both functions, a canonical UUIDv4 succeeds and returns identical 16 bytes; all-zero, wrong version nibble and wrong variant reject as `Corrupt`. Current `PlayerId::is_valid` must return exactly whether the domain player constructor succeeds for a table of canonical/malformed IDs. No fabricated absent domain ID. Existing hostile absent-target zero bytes remain a format sentinel and are not sent through `checked_player_id`. The new conversion test initially fails to compile because the public functions do not exist; its field/byte and rejection assertions are the behavioral oracle, not the missing import alone.

**Algorithm example:** `mornlea_domain::PlayerId::try_from_bytes(raw.to_bytes()).map_err(|_| corrupt("player ID", "not UUIDv4"))`; companion uses its distinct constructor. Change `is_valid` to delegate to domain rather than repeat nibble checks. No new crate dependency.

**Commands:** discover and run `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_storage --test safety_domain_values --locked identity_`; then full storage `runtime_contract`, `cargo clippy --manifest-path packages/engine/Cargo.toml -p mornlea_storage --all-targets --locked -- -D warnings`. Audit `src/identity.rs`: the UUID version/variant bit logic must exist only in `mornlea_domain`; storage must call the domain constructors rather than repeat masks. Record the removed duplicated rule lines in the ledger. **Commit:** `refactor(storage): share domain identity validation`. **Rollback:** this node's Rust/test commit.

## Node 3.2 — ordinary stacks and raw armor

**Prerequisite:** 3.1. **Editable:** `src/items.rs`, `src/lib.rs`, `tests/safety_domain_values.rs` stack section. **Read-only:** domain `items.rs`, Go `packages/shared/core/item.go`, Rust `src/player.rs`. **Produce:** `checked_item_stack(ItemStack)->StorageResult<mornlea_domain::ItemStack>` and retain the existing raw `ItemStack`, `Inventory`, `item_stack_limit`, `item_max_durability` crate-root names as thin format adapters.

**Cases:** exact empty triple accepted; item 1 count 64 accepted/count 65 rejected; item 66 rejected; durable item 10 durability 0 and 132 rejected while 1 and 131 accepted; nondurable item with durability 1 rejected; for all IDs 0..=66 and count/durability boundaries, storage `is_valid` equals domain `try_new` admission. Player armor raw (4242,65,999) must survive existing v9 encode/decode unchanged even though `checked_item_stack` rejects it; full `u16` exhaustion remains accepted. This is a rule-source refactor: the equality matrix may pass on baseline, and the source audit must show the duplicated item/stack/durability/smelting tables removed. The new checked conversion test must also run substantive valid/invalid cases.

**Algorithm:** call `mornlea_domain::ItemStack::try_new(raw.item,raw.count,raw.durability)`; map domain errors to `Corrupt` without clamping. Make storage limit/durability/smelting helpers delegate to the domain functions. Keep only numeric IDs needed for format fields and fixed slot counts, not a second registry table. Do not call this converter for the player's armor field.

**Commands:** discover and run `safety_domain_values stack_`; run `runtime_contract player_`, `runtime_contract companion_`, `runtime_contract chunk_` and domain `cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_domain --locked`. Audit `src/items.rs`: no independent per-item limit/durability/smelting match table remains; constants needed to spell a wire field or fixed slot count may remain. Record the removed duplicated table ranges and every retained constant's format reason. **Commit:** `refactor(storage): use domain ordinary item rules`. **Rollback:** revert this one node.

## Node 3.3 — compact section validation

**Prerequisite:** 3.2. **Editable:** `src/chunk.rs`, `src/lib.rs`, `tests/safety_domain_values.rs` section section. **Read-only:** domain `sections.rs`, Go `packages/server/storage/chunk/chunk_codec_logical.go`. **Produce:** `checked_section(&ContainerSnapshot)->StorageResult<mornlea_domain::PalettedSection>`.

**Cases:** single air and last registered block; indexed 4-bit and 8-bit with nontrivial palette and exact word arrays; direct 15-bit words; unknown block 90, empty/duplicate/oversized palette, wrong word count, out-of-range slot and high direct bits. Also reject single mode with nonzero `bits` or leftover palette/packed data, indexed mode with nonzero `single` or unused packed tail, and direct mode with nonzero `single` or any palette residue. For each valid case compare the returned domain `as_single/as_indexed/as_direct` views byte-for-byte with the input compact representation and `block_at` at first/last/selected cells. A malformed section returns `Corrupt` without partially returning a domain value. The checked API is initially absent; parity assertions, not import failure, are the oracle.

**Algorithm:** inspect `StorageKind` and run the existing mode-specific raw shape/residue checks before constructing a domain value: `single` requires zero bits and empty palette/packed; indexed requires zero single and the exact palette/word shape; direct requires zero single, empty palette and the exact direct word shape. The domain constructor owns the semantic per-cell scan, including palette indices and registered blocks; avoid calling the old full-cell scan again in the same path. Copy only bounded palette/word slices, map constructor failure to `Corrupt`, then reuse the converted sections for active-container `block_at` checks. Validate each of the 24 sections once; never expand a 98,304-cell dense buffer. Preserve raw DTOs for historical bytes and exact palette order.

**Commands:** discover/run `safety_domain_values section_`; run `safety_chunk_aggregate`, `runtime_contract chunk_`, domain `cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_domain --locked`, and storage clippy with `-D warnings`. Audit the final section path: raw residue/shape is checked exactly once before the domain constructor; registered-block and palette-index semantic scans are delegated to that constructor; active association only uses `block_at`. Record this call path in the ledger, including a count of 24 conversions for a valid chunk and no dense section allocation. **Commit:** `refactor(storage): validate sections through domain`. **Rollback:** revert this node; no format change.
