# F3 bounded worker packets

Read [00-client-contract.md](00-client-contract.md), [02-family-schemas.md](02-family-schemas.md), F3 design/delta spec and the accepted contract SHA. `C` means `packages/engine/crates/mornlea_client_core/`; `G` means `packages/engine/crates/mornlea_godot/`. All paths are repository-relative. Every Rust packet's test module is included by a controller-owned `C/tests/{session_replay,prediction_replay,presentation_contract,lifecycle_contract}.rs` entrypoint. Only the named packet owns its module; workers do not edit `lib.rs`, `mod.rs`, bridge, registry, catalog, fixture manifest or ledger. Focused command for module `m` in target `t`: `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_client_core --test t --locked m`; discovery command uses `-- --list` and must find nonzero cases. A red must be behavioral after the contract compiles, then the real provider must green. For every node, report accepted SHA, fixture hash, discovered/executed counts, exact failure/overflow observation and scoped rollback; the controller reviews/commits before a dependent node begins. Existing Go sources are read-only oracles, never worker edit targets.
