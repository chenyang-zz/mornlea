# F3 bounded worker packets

Read [00-client-contract.md](00-client-contract.md), F3 design/delta spec and the accepted contract SHA. `C` means `packages/engine/crates/mornlea_client_core/`; `G` means `packages/engine/crates/mornlea_godot/`. All paths are repository-relative. Every Rust packet's test module is included by a controller-owned `C/tests/{session_replay,prediction_replay,presentation_contract,lifecycle_contract}.rs` entrypoint. Only the named packet owns its module; workers do not edit `lib.rs`, `mod.rs`, bridge, registry, catalog, fixture manifest or ledger. Focused command for module `m` in target `t`: `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_client_core --test t --locked m`; discovery command uses `-- --list` and must find nonzero cases. A red must be behavioral after the contract compiles, then the real provider must green. For every node, report accepted SHA, fixture hash, discovered/executed counts, exact failure/overflow observation and scoped rollback; the controller reviews/commits before a dependent node begins. Existing Go sources are read-only oracles, never worker edit targets.

**1.3 Login/session observation — exclusive `C/src/session/login.rs`, `C/tests/session_replay/login.rs`, after 1.2; read `packages/client/runtime` session and `packages/client/cmd/mornlea-godot-core/step_test.go`.** State machine `Disconnected→Connecting→Handshaking→Admitted→Closing→Disconnected`; only `step` advances from a validated complete protocol observation. **1.4 Confirmed mirror and observation order — `C/src/session/mirror.rs`, `C/tests/session_replay/mirror.rs`, after 1.2.** Apply a complete decoded server observation into a staging mirror, validate entity/chunk IDs and revision, then swap and increment `ConfirmedRevision` exactly once. ## Independent C1/C2 providers

**2.1 Typed input translation — `C/src/input.rs`, `C/tests/prediction_replay/input.rs`, after 1.2; read `packages/client/client/input.go`.** Convert one versioned `InputBatch` of keyboard/controller/pointer actions into protocol intents; validate every enum, finite ray, epoch, sequence and permission-facing shape before any queue insertion. Keep a single increasing local sequence per epoch, never consume it on validation/capacity error. Cases: ordered press/release, invalid ray NaN, stale epoch, duplicate sequence, 128/129 events and reset sequence. Run prediction filter and `go test ./packages/client/client -run Input -count=1`.

**2.2 Reversible prediction — `C/src/prediction.rs`, `C/tests/prediction_replay/correction.rs`, after 1.4 and 2.1; read `packages/client/runtime/prediction.go`.** Journal accepted local input by epoch/sequence, run F1 numerical kernel from last confirmed player state, and on correction discard acknowledged inputs then replay remaining entries in order. A duplicate acknowledgment has no effect; rejected intent is removed; reset clears journal and prediction. Cases: three pending controls with second acknowledged and server correction, duplicate ack, rejection, collision and old-epoch correction. Check predicted pose equals independent Go transcript within the frozen F1 numerical tolerance, not a fresh worker-selected epsilon. Run prediction filter and `go test ./packages/client/runtime -run Prediction -count=1`.

**2.3 Preparation scheduling — `C/src/preparation.rs`, `C/tests/presentation_contract/preparation.rs`, after 1.4.** Accept immutable mirror revision snapshots, process at most `work.meshes` CPU preparation completions, carry remainder FIFO and reject results from old epoch/generation/content revision. At most 64 pending results under the proposed C1 cap; a full queue rejects without dropping an accepted removal. Order removals before upserts for reused section key. Cases: 0/4096/4097 work budget, 64/65 pending, late completion after forget/reset, newer revision beating stale completion. Run presentation filter and `go test ./packages/client/client -run 'Mesher|Backpressure' -count=1`.

**2.4 Atomic frame validation — controller, after 1.4, 2.3 and all 2.5–2.9 family providers; exclusive `C/src/presentation/frame.rs`, `C/tests/presentation_contract/frame.rs`.** Validate all family headers and total 4096 records per family/4 MiB frame payload before one `Arc` swap; increment `frame_index` only on success. The old snapshot remains readable after any failure. Cases: one family with wrong epoch, mixed confirmed revisions, 4096/4097 records, byte cap/+1, repeated local frame within one confirmed revision, invalid numeric field. Run full `presentation_contract` and `go test ./packages/client/presentation -run Frame -count=1`. This is the one frame-publication editor.

**2.5 Terrain semantic family — `C/src/presentation/family_terrain.rs`, `C/tests/presentation_contract/terrain.rs`, after 1.2/2.3.** Publish dimension/section/revision/generation, material/light and stable prepared-resource reference, ordered `Remove` then `Upsert`.
