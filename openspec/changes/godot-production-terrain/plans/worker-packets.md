# P8 terrain implementation packets

The F3 accepted `terrain@1` schema and G1 descriptor SHA, F2 world replay, F1 K0 kernels, and this change's design/delta spec are prerequisites. `tasks.md` owns status. All paths are repository-relative and exact file owners below; every other file is read-only. `packages/engine/crates/mornlea_client_core/src/presentation/family_terrain.rs` is the accepted F3 producer and **not** a P8 worker edit target. The controller owns test entrypoints, fixture manifest, `feature.tres`, catalogs and ledger. A new `tests/terrain_contract.rs` target plus file-per-packet modules is prospective. Each worker first adds its named behavioral failing case, runs the named filter after target registration, implements its owned module, then runs the focused gate and reports SHA/fixture/count/error/rollback for a controller scoped commit. No pixel candidate is a semantic or provider pass.

**1.1 Inventory and budget freeze — controller.** Edit only `testdata/runtime-migration/client/terrain-cases.json` and `ledger.md`; enumerate current chunk/material/light/fog/LOD/visibility cases from `packages/client/mesh`, `packages/client/runtime/mesh.go`, and the existing `testdata/visual-golden/world` registry. Bind each to `terrain@1` and expected P8 test. Pin per-frame host request to 64 messages/32 mesh results, maximum 4096 terrain records and 4 MiB frame payload inherited from F3; pool count may not exceed the accepted family record cap. Count only observed supported view distances, list each by fixture instead of inventing a new range. Missing case or unaccepted G1 descriptor is a failing gate. Run `go test ./packages/client/mesh -count=1` and `make godot-terrain-check` as characterization.

**1.2 Test seam — controller after 1.1.** Create `packages/engine/crates/mornlea_client_core/tests/terrain_contract.rs`, its module directory, and `apps/mornlea-godot/tests/scripts/terrain_rust_core_check.py`; register nonempty cases for valid section and stale generation. Make the provider double return a deliberately stale generation so `terrain_contract` behaviorally reds, then validate F3 real producer greens. Run `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_client_core --test terrain_contract --locked -- --list` and the target. No feature is enabled.

**2.1 Typed bulk conversion — worker owns `packages/engine/crates/mornlea_godot/src/terrain_bridge.rs` and `packages/engine/crates/mornlea_client_core/tests/terrain_contract/bulk.rs`; read F3 family and existing `quad_decode.rs`.** Convert validated `terrain@1` records into owned Godot-ready opaque/cutout/water batches without copying raw server packets into Python; validate count, byte length, finite coordinates and revision before replacing the visible batch. Cases: one record per material class, invalid length, 4096/4097 records, stale epoch, failed conversion retains prior batch. Run terrain Rust filter and `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_godot --locked`. A collision with F3 bridge edits blocks dispatch until 3.1 is accepted.

**2.2 Resource pool — worker owns `packages/engine/crates/mornlea_godot/src/terrain_resources.rs` and `packages/engine/crates/mornlea_client_core/tests/terrain_contract/resources.rs`; read Godot feature `terrain_near`.** Key resource by `(epoch, dimension, section, generation, content_revision)`; remove old key before upsert, release GPU handle on Godot owner thread, and bound live resources by the 4096-record family cap. Cases: remove/reuse same section, old-epoch completion, pool 4096/4097, disable with queued resources and double release. Run terrain filter and `make godot-terrain-check`. This worker never edits `terrain_bridge.rs`.

**2.3 Preparation completion — worker owns `packages/engine/crates/mornlea_godot/src/mesh_worker.rs` and `packages/engine/crates/mornlea_client_core/tests/terrain_contract/completion.rs`; read F3 preparation contract.** Drain at most 32 mesh completions per host step; preserve accepted FIFO, discard completion with old epoch/generation/revision, count discarded and pending. Cases: 0/32/33 work, late completion after forget/reset, cancellation, newest revision wins. Run terrain filter and `make godot-terrain-check`. Do not change F3 scheduler or shared `lib.rs`.

**2.4 Godot near terrain — worker owns `apps/mornlea-godot/features/world/terrain_near/terrain_near_component.py`, `terrain_near.tscn`, and `apps/mornlea-godot/tests/scripts/terrain_rust_core_check.py`; read F3 typed frame.** Apply one validated bulk batch per `_process`, require matching epoch/revision, and queue release on feature deactivate. First test no partial update on invalid batch, same-section replacement, reset and 32/33 upload work with a fake bridge. Run `make godot-python-check`, `make godot-terrain-check`, `make godot-project-check`. Do not parse raw mesh/wire buffers or add a Python mesher.

**2.5a LOD transition — worker after 2.4, exclusive new `apps/mornlea-godot/features/world/terrain_lod/{terrain_lod_feature.py,terrain_lod.tscn,AGENTS.md}` and `apps/mornlea-godot/tests/scripts/terrain_lod_check.py`.** Consume `terrain@1` visibility/revision, transition near↔far and remove without duplicate live section. Test horizon transition, unload/reload, stale generation and reset. Run `make godot-terrain-check`, `make godot-project-check`. No tracked images change.

**2.5b Material, light and fog — separate worker after 2.4, exclusive `apps/mornlea-godot/features/world/terrain_near/terrain_near_{opaque,cutout,water}.gdshader` and `apps/mornlea-godot/tests/scripts/terrain_material_check.py`.** Consume typed light/material parameters; test opaque/cutout/water, skylight tunnel, underwater, rainy/snow scene and missing asset failure.
