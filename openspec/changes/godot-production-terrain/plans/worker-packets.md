# P8 terrain implementation packets

The F3 accepted `terrain@1` schema and G1 descriptor SHA, F2 world replay, F1 K0 kernels, and this change's design/delta spec are prerequisites. `tasks.md` owns status. All paths are repository-relative and exact file owners below; every other file is read-only. `packages/engine/crates/mornlea_client_core/src/presentation/family_terrain.rs` is the accepted F3 producer and **not** a P8 worker edit target. The controller owns test entrypoints, fixture manifest, `feature.tres`, catalogs and ledger. A new `tests/terrain_contract.rs` target plus file-per-packet modules is prospective. Each worker first adds its named behavioral failing case, runs the named filter after target registration, implements its owned module, then runs the focused gate and reports SHA/fixture/count/error/rollback for a controller scoped commit. No pixel candidate is a semantic or provider pass.

**1.1 Inventory and budget freeze — controller.** Edit only `testdata/runtime-migration/client/terrain-cases.json` and `ledger.md`; enumerate current chunk/material/light/fog/LOD/visibility cases from `packages/client/mesh`, `packages/client/runtime/mesh.go`, and the existing `testdata/visual-golden/world` registry. Bind each to `terrain@1` and expected P8 test. Pin per-frame host request to the accepted F3 work budget (pilot 64 messages/32 mesh results), measured terrain family record cap and measured complete frame-byte cap (8 MiB proposed; 4 MiB was below an existing world batch). Measure and freeze separate maxima of concurrently live Near section and Far tile resources, plus their checked combined TerrainKey count/bytes; per-frame record count is not a live-pool bound. Far uploads consume the same64 host-frame resource upload slots as Near uploads, with at most the independently charged accepted C2 far byte budget; a full upload budget retains the FIFO remainder. Count only observed supported view distances, list each by fixture instead of inventing a new range. Missing case or unaccepted G1 descriptor is a failing gate. Run `go test ./packages/client/mesh -count=1` and `make godot-terrain-check` as characterization.

**1.2 Test seam — controller after 1.1.** Create `packages/engine/crates/mornlea_client_core/tests/terrain_contract.rs`, its module directory, and `apps/mornlea-godot/tests/scripts/terrain_rust_core_check.py`; register nonempty cases for valid section and stale generation. Make the provider double return a deliberately stale generation so `terrain_contract` behaviorally reds, then validate F3 real producer greens. Run `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_client_core --test terrain_contract --locked -- --list` and the target. No feature is enabled.

**2.1 Typed bulk conversion — worker after accepted F3 G1 SHA owns `packages/engine/crates/mornlea_godot/src/terrain_bridge.rs` and `packages/engine/crates/mornlea_client_core/tests/terrain_contract/bulk.rs`; read F3 family and existing `quad_decode.rs`.** Convert validated `terrain@1` records into owned Godot-ready opaque/cutout/water batches without copying raw server packets into Python; validate count, byte length, finite coordinates and revision before replacing the visible batch. Run terrain Rust filter and `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_godot --locked`. P8 3.1 is a downstream integration gate, never a prerequisite of this node.
