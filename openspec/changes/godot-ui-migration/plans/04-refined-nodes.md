## Local presentation control contract owned by 1.2

Controller owns `apps/mornlea-godot/features/ui/presentation_controls.py` and `apps/mornlea-godot/tests/scripts/ui_presentation_controls_check.py`, registering both in the shared harness. They expose `PresentationControls.snapshot()->PresentationSettings`, `set_draft(change:SettingsChange)->bool`, `save()->SettingsReceipt`, `cancel()->None`, `set_menu(MenuState)->None`, `set_focus(bool)->None`; MenuState is Main|Loading|Playing|Pause|Settings. These are local presentation values, never ClientIntent or an authoritative pause. Session observations choose Main/Loading/Playing; a local menu may suppress gameplay input but cannot create a session. Focus loss emits one neutral semantic PlayerInput through the owning input adapter, not per-Control duplicates.

PresentationSettings owns exactly audio_volume finite0..1, texture_pack_path single-line UTF-8<=1024bytes and window_size from the accepted source UI preset enum (`validUIWindowSize` in packages/client/client/ui_bridge.go). 1.1 inventories literal preset/default values and 1.2 pins them as closed examples before dispatch. SettingsChange is AudioVolume(float)|TexturePackPath(str)|WindowSize(preset). Draft changes have no running-state/disk effect; save validates all fields and returns Saved(snapshot)|Failed(reason) with committed/running state unchanged on failure; cancel restores committed draft. Offline source oracle is packages/client/cmd/mornlea/app/app_settings.go and its tests. New product resource selection resolves a licensed manifest entry; arbitrary absolute source paths never become runtime bridge payloads. No server settings enter this facade. Its persistence/backend port is injected in1.2 with success/failure doubles and implemented serially by P10 3.1; settings worker renders/dispatches only, not a second writer.

Tests pin invalid draft preserving old value, failed save preserving committed/running values, cancel, neutral focus-loss exactly once and menu changes producing no server pause command. Run `python3 apps/mornlea-godot/tests/scripts/ui_presentation_controls_check.py`, the UI harness and `go test ./packages/client/cmd/mornlea/app -run Settings -count=1`. 2.2/2.5b1 receive this accepted local facade and fixtures; G1 remains the sole world/session input facade.
