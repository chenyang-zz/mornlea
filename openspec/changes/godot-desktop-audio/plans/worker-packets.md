**2.1 Cue-to-resource mapping — worker owns `apps/mornlea-godot/platform/desktop/audio/cue_map.py`, `apps/mornlea-godot/tests/scripts/desktop_cue_map_check.py`; read F3 cue and 1.1 asset inventory.** Resolve only manifest-listed hashed cue IDs to Godot resource keys; validate category, finite position, volume/pitch range and resource availability before playback. **2.2 Audio playback adapter — worker owns `apps/mornlea-godot/platform/desktop/audio/desktop_audio_feature.py`, `apps/mornlea-godot/tests/scripts/desktop_audio_check.py`; after 2.1.** Consume ordered `audio-cues@1` once by its accepted F3 `CueProvenance` key; fake/no-device consumes semantic cue without later replay burst; stop/release channels on deactivate on the Godot thread. **2.3 Desktop input — worker owns `apps/mornlea-godot/platform/desktop/input/desktop_input_feature.py`, `apps/mornlea-godot/tests/scripts/desktop_input_check.py`; read F3 input.** Fold up to 128 keyboard/mouse/controller device events into one per-frame semantic `PlayerInput` plus ordered discrete actions, then submit the whole typed `InputBatch` through F3. Reject either >128 device events or >128 resulting semantic actions without partial enqueue. Test press/release, zero-event neutral frame, controller unplug, focus loss while moving, pointer invalid ray, 128/129 device events, 128 discrete actions plus aggregate overflow, and repeated reset. Run `make godot-input-check`, `make godot-python-check`, `make godot-smoke`. No direct server/world mutation.

Test activate→reset→deactivate, double deactivate, callback after close, optional audio failure preserving session and 100 no-device cycles. Run `scripts/godot/audio-check.sh`, `make godot-input-check`, `make godot-python-check`.
