## Node 5.1 — closed executed corpus

**Prerequisites:** every checked node through 4.6b. **Deliverable:** all seven save families and every supported version/operation have actual Go and Rust executions with bound assets, complete route registration and zero storage coverage gaps. **Editable:** Go `packages/tools/cmd/runtime-oracle/storage_coverage_test.go`, `inventory.go` source revision/registry, Rust `packages/engine/crates/mornlea_storage/tests/storage_corpus.rs`, reviewed `testdata/runtime-migration/contracts.json` and reviewed per-case assets; these shared files are controller-owned. Family producer and Rust module files are read-only unless a failed case is routed to its owning node.

**Exact closed set:** `save.chunk` decode versions 1..9 and encode 9; `save.player` decode 1..9 and encode 9; `save.companion` decode 1..5 and encode 5; `save.hostile` decode 1..2 and encode 2; `save.passive` decode/encode 1; `save.region` decode/encode/order 1; `save.world-metadata` decode 1..6 and encode 6. For each supported decode version require at least one accepted case and one invalid or boundary case that executes; for each non-chunk current encode require a valid case and a rejection/short-capacity case. Chunk encode requires a valid logical-byte corpus case plus node 4.2's local Rust N-1/N/N+7 capacity gate; no Go compressed-size oracle is claimed. A claimed route with zero cases, a case with no producer/consumer, duplicate case ID, unsupported version, missing source hash, changed asset digest, missing checkpoint or unknown operation fails. No `save.*` point remains in the report's `Uncovered` list; non-storage F1 points may remain and do not count as storage failure.

**Mutation oracle:** starting from a fully passing manifest, change one `value_sha256`, one input digest, one encoded byte reference, one version, one route, and delete one case in separate test copies. Each must fail Go reconciliation or the real Rust comparator for the intended reason. For every family select two valid cases on the same decode route with different Go `value_sha256`; call the real Rust dispatcher with case A's expected result and case B's valid input/arguments. The actual value digest must differ from A. This in-memory cross-input test rejects an adapter that merely returns frozen expected JSON, without a brittle source scanner or a tracked manifest rewrite. Region uses two bank cases (the superblock empty result cannot supply this mutation). One case with two checkpoints or a nonzero stateless checkpoint fails. Expected totals are discovered from the reviewed manifest; do not hardcode a guessed case count as the only proof.

**Integration algorithm:** prior family nodes already integrated one reviewed external selection at a time while preserving the old equal revision fields. Recheck their asset digests and producer source hashes, the complete sorted manifest, and the prior family result SHA. Capture that **committed SHA containing all producers and cases** as the new Go producer baseline; update manifest `source_revision` and Go `BaselineSourceRevision` together once, then reconcile the in-memory and reloaded manifest against `Discover` and `BaselineConsumerRegistry`. Run every family producer, Go inventory/trace package and all Rust corpus consumers of `contracts.json` (storage, domain, protocol, engine) at that identity. Existing unrelated cases, source hashes and fixture bytes remain unchanged unless their actual source file was edited and a justified hash refresh is recorded.

**Commands:** `go test ./packages/tools/cmd/runtime-oracle -run '^TestStorageCorpus' -count=1`; `go test ./packages/tools/cmd/runtime-oracle -race -count=1`; `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_storage --test storage_corpus --locked -- --list` then execution; `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_domain -p mornlea_protocol -p mornlea_engine --tests --locked`; `go test ./packages/audit -count=1`; `git diff --check`. Record discovered/executed counts, each family/version matrix, digest, source SHA, mutation results and rollback in `ledger.md`. **Commit:** `test(storage): close executable save corpus`. **Rollback:** revert the closure manifest revision plus any failing family's reviewed candidate/assets; never regenerate source fixtures in place.
