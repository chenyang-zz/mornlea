# Refined node decisions

Unsplit nodes retain the exact files, APIs, algorithms, red/green cases, commands and rollback in the existing worker packet. The dependency register adds readiness requirements and does not grant edits to shared files.

Editable: `apps/mornlea-godot/tests/scripts/migration_motion_capture.py`, `apps/mornlea-godot/tests/scripts/migration_motion_capture_check.py`; still capture/dispatcher/registry are read-only. Consume the same T1 accepted schema and explicit start/action/end/sample windows. Reuse only accepted public capture input/output values, never import a sibling feature implementation. Tests pin missing action boundary, zero sample, out-of-window/old-epoch frame, cancellation and incomplete final sample. Valid output records ordered timing, hashes and nonzero samples for human review; there is no automated GIF pixel verdict. Run `python3 apps/mornlea-godot/tests/scripts/migration_motion_capture_check.py`, `make godot-python-check`, `make godot-project-check` and the real no-focus motion script. Commit/rollback only motion files. 2.2c integrates both accepted providers and strict report after 2.3; it owns `migration_capture_check.py` and CLI dispatch, avoiding concurrent wrapper edits.

Test mixed UI/world/motion ownership with one missing legacy case and a writer touching motion: both must fail, all retained canonical cases must execute and old bytes remain identical.
