## Exact private owner and behavior

DeferredCommands (pub(super), Default) has records:Vec<CommandEnvelope>, index:BTreeMap<(u64,u64,u64,u64),usize>, and phases:[Vec<usize>;PHASE_COUNT]. Derive PHASE_COUNT from RulePhase::EnvironmentEnd as usize +1 (currently34). Key is (command.tick(),session(),sequence(),arrival_index()), retaining all ordering scalars; detached fixtures commonly reuse arrival0 with distinct sequences, so session/arrival alone is insufficient. Unique records/index each<=EFFECT_BUDGET4,096. Each phase list separately holds<=4,096 references, including repeated occurrences; metadata maximum34*4,096 integer references, actual one-pass production has at most2 references per admitted envelope across four used roles. No extra command payload copy or history survives TickContext drop. Default uses empty Vec/map and std::array::from_fn(|_|Vec::new()), not a4,096-record allocation on every empty tick.

Expose pub(super) defer(&mut self,command:CommandEnvelope,phase:RulePhase)->Result<(),ServerError> and for_phase(&self,phase:RulePhase)->Vec<CommandEnvelope>. TickContext public signatures stay unchanged and delegate. No new public observation getter or provider edit.

Algorithm: get the private phase list by phase as usize, with Internal{invariant:"deferred phase space"} on impossible ordinal exhaustion. Look up the full scalar key; existing record must equal the complete immutable envelope, or return Internal{invariant:"deferred command identity"} with original owners/roles untouched. Next refuse a full selected phase list exactly Capacity{resource:Commands,limit:4,096,observed:4,097}; a new unique record also requires records.len()<4,096 before either insertion, with the same Capacity. If the key exists, append its ordinal to that phase list EVERY time, preserving repeated same-phase delivery and cross-role references even at unique-owner capacity. Otherwise append one whole envelope, index its actual Vec ordinal and append that ordinal to the phase list. for_phase maps its list's original occurrence order to at most4,096 copied envelopes, preserving repeated payloads without consuming/mutating records or iterating index order. Invalid raw controls remain ordinary provider refusals; their admitted Motion and Interaction roles both survive. Current command floats are checked finite LookAngles, so clone equality is meaningful; same-key conflicting payload and phase-space exhaustion are trusted-boundary diagnostics, not new wire refusals.

No eager target/ray classification, source-capacity increase, phase reordering, command re-carry, counter suppression, batch truncation or error swallowing repair is included. Final reducer/hard errors remain root-owned successors.
