# Refined node decisions

Unsplit nodes retain the exact files, APIs, algorithms, red/green cases, commands and rollback in the existing worker packet. The dependency register adds readiness requirements and does not grant edits to shared files.

These packets replace original parents `1.1` and `1.5`. Read [S1 seams](02-core-seams.md) and [predecessors](03-parallel-readiness.md). Paths are repository-relative. Final F1 is a hard entry gate. Shared contract/module/test registrations remain controller-owned.

Editable: `testdata/runtime-migration/server/capability-inventory.json`, `ledger.md`. Read-only: accepted foundation-successor ledger/corpus, command/event and protocol/save registries, `packages/server/sim/runtime/engine_step.go`, `packages/server/sim/entity/tick.go`, current server tests. Later 1.2 registers `tests/server_contract/inventory.rs` with unknown/missing/duplicate assertions against this fixture. Commit inventory/ledger only; rollback removes this mapping and blocks descendants.

## Node 1.1b: Actual admission high-water

Editable: `testdata/runtime-migration/server/capacity-measurements.json`, `packages/server/sim/runtime/migration_capacity_oracle_test.go`, `packages/server/server/persistence/migration_capacity_oracle_test.go`, `ledger.md`. Production Go and the foundation corpus are read-only. Add test-only `TestMigrationCapacityReplay` in the runtime package for command/chunk queues and `TestMigrationPersistenceCapacityReplay` inside package `persistence` for private save queue/retry ownership. Each uses only package-local access and an injected deterministic worker; runtime cannot import upstream server persistence. The persistence test drives `NewWorld`, `Observe`, `schedulePersistenceLocked`, `dispatchPersistenceLocked`, `dispatchDueRetriesLocked`, `drainSaveCompletionsLocked` and `applySaveCompletionLocked` through the existing package-local harness and samples private pending-job/chunk/owned-byte fields immediately before/after each owner operation; no public Status aggregate is labeled a high-water. Freeze test helper `observeMigrationCapacity(caseID, boundary string, records, ownedBytes int)` returning an owned sample, retained by the test only. Construct the package-local workerless `World` owner as in `world_retry_test.go`, with explicit saveJobs/retry/retryInFlight state; do not call NewWorld for this owner because it immediately starts goroutines. Drive the real dispatch methods and explicitly dequeue one job/submit one completion per action. Separately exercise the real saveWorker with a gated Store and include its held job in the ownership sample. Tests run schedules one operation at a time so no unobserved concurrent queue peak is inferred. Every inventory replay supplies command/chunk samples and applicable persistence schedules; not-applicable cases are explicit, never zero samples passed as coverage. Record commands, ready chunk results, pending save chunks/exact encoded bytes, sample count, maximum and boundary location with case/source hashes. Compute actual Go codec encoded length offline for every queued/worker-held/retry snapshot; EstimatedBytes and Status.EstimatedBytes are recorded separately as estimates, never bytes owned by Rust. Count one logical ownership ticket once when queue/held/retryInFlight refer to the same retained job; a separately allocated job/copy counts separately even for equal chunk/revision. Report queue, held, retry and total encoded ownership separately; compare the configured pending Rust byte ceiling to their deduplicated total, not an average or scheduler estimate. Post-drain counts and averages are not maxima. Supported runs must fit proposed Rust ceilings 4096 commands, 64 ready results, eight pending chunk saves, 4 MiB pending save bytes. Over-ceiling or zero samples blocks 1.1c; workers cannot raise limits.

Inject schedules reaching 4096/4097 and 64/65; a deliberately understated report first fails, then real observed counts pass. Run `go test ./packages/server/sim/runtime -run '^TestMigrationCapacityReplay$' -count=1 -v` and `go test ./packages/server/server/persistence -run '^TestMigrationPersistenceCapacityReplay$' -count=1 -v`. Observers write immutable drafts only under explicit `MIGRATION_CAPACITY_EXPORT_DIR`; the controller merges both into the one tracked report with case-set/source-hash equality checks. The owning package's current test harness/accessor names are inventoried in 1.1a; if an owner boundary is not observable without a production edit, revise this node before dispatch instead of fabricating a measurement. Instrumentation stays test-only and is retained only as an offline migration oracle; final runtime counters belong to Rust. Commit observer/report; rollback invalidates the measurements.

## Node 1.5b: Retryable shutdown

Editable: `packages/engine/crates/mornlea_server/src/core/shutdown.rs`, `packages/engine/crates/mornlea_server/tests/server_contract/shutdown.rs`. Controller predeclares both in 1.2; publication/state/reducer/store remain read-only. Consume frozen Deadline/ShutdownReport and deterministic S3/reducer ports. Running→Closing→one final unpublished tick→frozen snapshots→ordered flush/sync/close→Closed. Retry resumes unfinished flush, never a second final tick; failed/expired flush retains lease and reports phase/outstanding work.

Tests `shutdown::buffered_command_once_no_publication`, `shutdown::timeout_resume_without_second_tick`, `shutdown::failed_sync_retains_lease`, `shutdown::closed_idempotent` first fail behaviorally, then pass the real lifecycle with doubles. Run the Rust `server_contract` target filtered by `shutdown` and `go test ./packages/server/server -run Shutdown -count=1`. Nodes 3.1/3.7 repeat with real reducer/store. Commit the two files; rollback reverts their provider. No double closes integrated shutdown.

## Dispatch correction

For a module suite, use `... --locked <module>` without `-- --exact`; exact matching is only for a fully qualified test name discovered with `-- --list`. The original CT shorthand must not silently run zero tests. F2 1.2 registers the new shutdown files. The serial reducer remains the sole `core/step.rs` editor.
