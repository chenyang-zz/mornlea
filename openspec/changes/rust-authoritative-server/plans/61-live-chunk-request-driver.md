## Exact API and ownership

Add public core/chunk_driver.rs and export through core/mod.rs. `ChunkDriver` implements Default/new; methods `pending_loads()->usize`, `pending_generations()->usize`, `held_completions()->usize`, `last_error()->Option<ServerError>`, `stop_new()`, `start_load(&mut self, authority:&mut AuthorityState, loads:&mut dyn ChunkLoadPort, key:ChunkKey, deadline:Deadline)->Result<ChunkRequestId,ServerError>`, `start_generation(&mut self, authority:&mut AuthorityState, generations:&mut dyn GenerationPort, key:ChunkKey)->Result<ChunkRequestId,ServerError>`, and `poll(&mut self, authority:&mut AuthorityState, loads:&mut dyn ChunkLoadPort, generations:&mut dyn GenerationPort)->ChunkPollReport`. Public report is Clone/Copy/Debug/Default/Eq with `polled`, `offered`, `pending`, `retained`:usize and `first_error:Option<ServerError>`.

Authority must already have live chunks enabled; existing reservations enforce Running, desired key, phase and per-source lane capacity. Each private source map is keyed by ChunkKey and holds only key, generation, checked request, phase and optional owned AcquiredChunkEvent. Large result variants receive local allowances and ownership comments, no cloning Ready or prepared payloads. Different sources may use equal numeric request IDs. No consumed/cancelled key or request history is retained. Existing staged aliases remain authority-owned until Acquire; a successful offer removes the driver record but cannot free authority's charge early.

`start_*` first rejects stopped state with InvalidState(Closing), permanent correlation fault with its retained original error, or its own eight-record source limit with Capacity(ChunkRequests,8,9), before any authority/provider call. Duplicate current key refuses InvalidInput("chunk_driver_request"). Then reserve through authority BEFORE the actual port start. A port refusal aborts the unbound reservation with that exact typed error and returns it, preserving wanted Failed state; no cancellation is fabricated. A successful port start is retained in a driver record BEFORE binding. Bind succeeds ->Bound; impossible bind/abort refusal is a correlation fault, retains exact unbound reservation/request information, stops future starts and returns that original correlation refusal. An abort fault has no provider request, retains the original port error in the bounded quarantined record, and returns/records the abort refusal; ordinary start refusal still returns the port error. Never cancel an ambiguous duplicate alias, poll it as another target, retry its binding, or remove its ownership record. The actual accepted ports allocate unique checked aliases; negative doubles qualify this defensive branch only. No caller callback/reentrancy intervenes in the reserve/start/bind sequence.

`poll` visits at most16 current records in source Load then Generated order, and ChunkKey order within each source. Quarantined unbound starts remain retained and are never polled. Each Bound record without held body is polled once through its corresponding source port; Pending counts pending, while loaded/missing/ready/typed failure converts to one original owned AcquiredChunkEvent. Every held event attempts authority.offer_acquired at most once per call. Success removes only that record and increments offered; queue capacity refusal retains the returned event unchanged without a permanent correlation fault; Closed/disabled state likewise retains and reports the typed error. Other identity/ownership refusal retains event and sets the first permanent correlation fault. Record diagnostics are one bounded Option, not error history. `first_error` reports this call's first refusal while independent successful offers remain settled. `polled` counts actual port polls; `retained` is the final driver record count. A successfully offered typed Failed completion is not a driver refusal: Acquire owns its Failed transition.

`stop_new` is idempotent and prevents new port starts, while poll still drains bound requests into authority during Closing for a final retained batch. Forgotten started work is not cancelled; saved success must reach Unloading, missing success removes the forgotten record, and generated success likewise installs Unloading according to accepted source behavior. Dropping the driver makes no cancellation, quiescence or join claim. Actual runtime owns provider stop/cancel/wait/close; its later composition must prove native owners joined before releasing the borrowed runtime. This node adds no WorkerLifecycle implementation or invented quiescence token.
