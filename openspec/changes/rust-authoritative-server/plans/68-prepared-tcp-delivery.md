## Frozen method and queue representation

Add this public method to the existing TcpTransport impl:

```rust
pub fn forward_prepared_outbox<T: TransportAuthority + PreparedPublicationPort>(
    &mut self, id: ConnectionId, session: SessionKey, endpoint: &mut T,
    max_frames: usize, max_bytes: usize,
) -> std::io::Result<usize>;
```

T is sized, so the same actual concrete borrowed LiveEndpoint can supply the narrow prepared drain and coerce to the existing TransportAuthority for control acknowledgments. Do not alter TransportAuthority or create a marker/compound trait. Return value counts whole owners moved into this socket queue, not bytes written or peer acknowledgments. Fatal socket failure still returns its actual io::Error; queued authority receipt and later connection failure are separate events.

Add Queued::Prepared(PreparedFrame), bytes() borrows frame.as_bytes(), is_core() remains true ONLY for Core. No raw construction, body clone, encoding, into_legacy_bytes conversion or alternate framing. Existing Core(Vec<u8>)/Outbox(Vec<u8>) and legacy forward_outbox returned-copy behavior remain unchanged. Prepared and existing lanes share the same VecDeque and partial head.

## Ordered transfer and failure algorithm

1. Check core.active_session(id)==Some(session) before querying authority or mutating any queue; otherwise same existing InvalidInput I/O error/message "connection does not own the session". Missing socket -> same NotConnected/message "connection has no socket". This rejects prelogin, wrong/reconnected session, closed connection and unknown connection without dropping authority frames.
2. available=512.saturating_sub(conn.queue.len()). If available0 or max_frames0 return Ok(0) with authority FIFO untouched, no optimistic draining. Otherwise call endpoint.take_prepared_outbox(session,max_frames.min(available),max_bytes). Map its refusal to the same legacy NotConnected/message "session outbox is gone". The accepted real provider enforces whole frames/count/first-oversized rules; do not re-encode/repartition/skip or discard a nonfit suffix.
3. Record moved=envelopes.len(); move every exact owner into conn.queue.push_back(Queued::Prepared(frame)), preserving one FIFO and its <=512 count. No body/owner clone is needed. drain_queue then attempts at most64 writes including Interrupted and at most1MiB actual bytes, exactly as existing code. WouldBlock keeps the unchanged head/suffix for later flush_out; subsequent control frames append behind that suffix. No new wait/sleep or socket option/policy.
4. Pass only result.sent_core to existing core.ack_sent(id,...,endpoint). Prepared frames never acknowledge LoginSuccess or advance its ledger. Preserve existing fatal ordering: completed control acknowledgments settle before a later socket failure; fatal -> shut_locked PeerGone and return original error. Closed progress -> drop_stream. Otherwise return Ok(moved), even when the bounded nonblocking writer leaves some transferred owners queued. Existing flush_out drains the new lane through bytes()/is_core() with unchanged budget/retirement behavior.

Bounds remain actual configured authority<=512 canonical frames plus existing TCP<=512 shared send frames, each at most MAX_FRAME_BYTES+5; transferred Vec length<=available. This packet claims per-owner/socket bounds, not global historical session retention or a compressed-byte source parity result. No caller mirror advances on this returned count; source mirror receipt remains accepted Queued at authority admission.
