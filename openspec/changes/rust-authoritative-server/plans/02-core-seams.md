# F2 accepted-contract landing specification

This file defines prospective S1–S4 declarations, not existing runtime APIs. Node 1.2 owns every declaration below in `mornlea_server/src/core/contracts.rs`, its private backing state in `state.rs`, and executable success/failure consumer doubles. Consumers cite its accepted implementation SHA. Imports are the accepted F1 `mornlea_domain`, `mornlea_protocol`, `mornlea_storage` and safe numerical APIs; a mismatch returns to the controller, never a worker alias. [Execution](00-execution.md), [provider packets](01-server-slices.md) and [algorithm/acceptance tables](04-refined-nodes.md) are read together.

## Identity, errors, admission and clock

Existing identities are `PlayerId`/`CompanionId` (checked UUID bytes), `HostileId`/`PassiveId`/`ProjectileId` (checked u64), `Dimension`, `BlockPos`, `ChunkPos`, `ContainerRef`, `DropId`, `ItemStack`, `MotionState`, `SurvivalState`, `CommandEnvelope`, `RoutedEvent` and protocol `AdmittedLogin`/`PlayIntent`. There is no existing `BlockId`, `ItemId` or `CompanionKey`: block/item fields below are checked u16 using `registered_block`/item validation. New `SessionKey`, `SaveTicket`, `ChunkRequestId`, `ConnectionId` wrap nonzero u64 with private fields; allocate monotonically and never reuse during a process. New `AgentRequestId`, `RunId`, `SnapshotId`, `LeaseId`, `NamespaceId`, `ClientInstanceId`, `OperationId` are checked canonical UUIDv4 wrappers, never interchangeable. `ActorKey = Player(SessionKey) | Companion(CompanionId) | Hostile(HostileId) | Passive(PassiveId)`; only the first two can perform inventory transactions. System/graze world mutation uses the explicit producer below.

`ServerError = InvalidInput{field: &'static str} | IncompatibleVersion{family: &'static str, found:u32} | InvalidState{phase:ServerPhase} | StaleSession{session:SessionKey} | Capacity{resource:Resource,limit:usize,observed:usize} | Timeout{operation:Operation} | Cancelled | Disconnected | Io{operation:Operation,kind:std::io::ErrorKind} | Agent{code:AgentErrorCode,status:u16} | Internal{invariant:&'static str}`. `ServerPhase = Running | Closing | Closed`; `Resource = Players | Commands | Arrivals | ChunkResults | Outbox | PendingLogins | SaveChunks | SaveBytes | AgentRuns | Snapshots | RuleEffects`. `Operation = Load | WritePayload | SyncPayload | WriteBank | SyncBank | Replace | DirectorySync | Flush | Sync | ReleaseAgent | Close | Shutdown | AgentRpc | Transport`. Credentials, raw bodies and private buffers never enter error details. `RuleReject = Wire(mornlea_domain::RejectReason) | StaleObservation | DuplicateProvenance | CancelledGeneration | ResourceFull(Resource)`. Internal classifications are distinct from a wire event.

`ServerLimits::try_new(max_players:u8,queued_commands:usize,session_outbox:usize,ready_chunk_results:usize,snapshot_chunks:usize,snapshot_bytes:usize)` returns checked private fields/read-only same-name getters: maxima 8/4096/512/64/64/1048576. These are planned maxima, accepted only after 1.1b supported-run fit evidence. `TickBudget::try_new(commands:usize,fluid_updates_per_dimension:usize,fluid_rescan_target_per_dimension:usize,farmland_checks:usize,farmland_block_reads:usize)` accepts zero work and ceilings 4096/512/65536/65536/65536. The fluid rescan target is checked before each 4096-cell section: actual work can exceed the target by at most 4095 cells per dimension. Farmland counters are global across dimensions. Revalidate forged values at `advance_tick` before draining. Checked capacity arithmetic fails before allocation; no partial state change.

`Clock` has `fn monotonic(&self)->Instant` and `fn unix_ms(&self)->i64`; `Deadline::at(Instant)`, `after(now:Instant,timeout:Duration)->Result<Deadline,ServerError>`, `expired(now:Instant)->bool` use checked addition. Wall time is used only by the versioned Agent deadline/TTL contract, never to reconstruct monotonic deadlines. `ServerEndpoint::shutdown(deadline:Deadline)->Result<ShutdownReport,ShutdownFailure>` replaces its earlier error-only return. Other endpoint signatures remain in 00.

Intake checks live session, Running phase, validated whole payload, queue capacity and arrival-index availability, then assigns `(earliest_tick=state.next_tick, arrival_index=per_session_counter)` atomically. The counter starts at zero, never resets, and exhaustion refuses the new record without mutation. **Do not reject or advance sequence at arrival.** Freeze all eligible records at tick start, sort by `(earliest_tick,session,sequence,arrival_index)` using accepted F1 ordering, apply a budgeted prefix, carry the suffix with original earliest tick/arrival identity. Applied watermark starts at zero; sequence <= watermark is silently discarded; update only when a sequence is consumed by command execution. A receipt `QueuedForTick{tick,arrival_index}` names earliest eligibility, not guaranteed execution or success. The publication/counters record actual execution tick separately. Zero budget carries everything. Small-budget cases are target scheduling tests; Go parity uses the full supported batch. Queue saturation consumes no watermark/index. Chat and keepalive are control-plane inputs with no domain sequence.

| Failure | Memory and TCP observable policy |
| --- | --- |
| Decoded hello version mismatch | Existing HandshakeReject version-mismatch, then close. Malformed frame/hello closes silently. |
| Invalid login identity / view distance / duplicate / active full / corrupt player / load I/O / attach failure | Existing LoginReject codes 2 / 5 / 7 / 1 / 3 / 4 / 6 respectively, then close. Prelogin cap17 closes silently. |
| Stale/duplicate applied sequence or disappeared session in tick batch | Silent no-effect; zero CommandRejected. |
| Gameplay `RuleReject::Wire(reason)` | Existing v45 CommandRejected with original sequence and one of its 15 reasons. |
| Internal queue capacity, closed session/phase, codec/semantic error, EOF, full outbox, writer failure | Close affected connection silently; diagnostics retain internal class. No invented Capacity/stale wire reason. |
| Invalid heartbeat token / unknown play message / heartbeat timeout | Best-effort existing Disconnect protocol-violation / protocol-violation / timeout, then close (send bound200ms). |

Stage validates the whole owned effect before updating the visible overlay; subsequent phases read that overlay. A rejected atomic effect leaves all components/events unchanged. Once a phase has applied valid commands, a later isolated command rejection does not undo earlier commands; fatal precommit infrastructure failure discards the entire overlay and retains eligible inputs for retry. Commit publishes one revision advance per changed chunk, not one revision per block.

## Atomic world/inventory effects and provider tests

## S2 common connection boundary

3.2 lands `ConnectionCore` in `transport/common.rs` and a compiling deterministic endpoint consumer before3.3a/b. `open(kind:TransportKind,now:Instant)->Result<ConnectionId,ServerError>` reserves prelogin; `ingest(id,bytes:Vec<u8>,terminal:bool,endpoint:&mut dyn TransportAuthority,clock:&dyn Clock)->ConnectionProgress`; `poll(id,endpoint:&mut dyn TransportAuthority,clock:&dyn Clock)->ConnectionProgress`; `take_frames(id,max_frames:usize,max_bytes:usize)->Vec<Vec<u8>>`; `close(id,reason:CloseReason,endpoint:&mut dyn TransportAuthority)`. `ConnectionProgress = AwaitMore | Advanced{frames:usize} | Closed{reason:CloseReason,class:Option<ServerError>}`. States Hello→Login→Play→Closed; transition to Play only after LoginSuccess enters owned outbound queue. Hello5s/login10s deadlines include player loading and success handoff; pending limit16 distinct from active8. Buffer each incomplete frame up to2MiB body+5-byte prefix; parse canonical length before body allocation. `Truncated` with terminal=false waits; terminal=true closes silently. Coalesced bytes process at most64 frames/1MiB per poll (a single valid >1MiB frame is processed alone), retaining remaining owned bytes. Total admitted receive storage per connection is one2MiB+5 frame plus one bounded incoming chunk of the same size; reject oversized chunks before copy. No borrowed FrameRef escapes conversion.

After login heartbeat interval5s/timeout15s with at most one outstanding nonzero monotonic token; duplicate/mismatch closes with existing violation, outstanding suppresses a new probe, matching reply clears only current token. Outbox512 frames, adapter-to-core global4096 commands; adapter cannot hide an unbounded secondary queue. A socket owner waiting on core capacity is cancelled/closed by that same connection owner. All transports use this exact core/error matrix. Send buffers transfer ownership; max512 frames/1MiB per drain, oversized valid first frame alone. TCP read/write owner gates independent; operation cancellation/deadline is recoverable, EOF/codec/otherI/O closes connection; cleanup removes operation deadlines before reuse.

## S3 snapshots, filesystem and completion acknowledgment

`SaveKey = Chunk(ChunkKey) | Player(PlayerId) | Companions | Hostiles | Passives | Metadata`; `SaveMode = Urgent | All`; `SaveUrgency = Unload | Autosave | Shutdown`. `SaveBudget{chunks:usize,estimated_bytes:usize}` defaults8/4194304 is a **selection** budget, allowing oversized first snapshot. `StoreHandle` exact ports: `submit(request:SaveRequest)->Result<SaveTicket,SubmitSaveError>`; `poll(ticket:SaveTicket)->SavePoll`; `poll_tick(tick:u64,budget:SaveBudget,authority:&mut dyn SaveAuthority)->Result<SaveScheduleReport,ServerError>`; `cancel_pending()->Result<Vec<OwnedSnapshot>,ServerError>` (returns unstarted ownership, cannot retract committed work); `flush(deadline:Deadline,authority:&mut dyn SaveAuthority,clock:&dyn Clock)->Result<FlushReport,ServerError>`; `sync(deadline:Deadline)->Result<(),ServerError>`; `close(deadline:Deadline)->Result<(),ServerError>`. Only flush/sync/close block outside tick. `DiskBackend::write(ticket:SaveTicket,request:SaveRequest)->SaveCompletion`, `load(key:SaveKey)->Result<SaveValue,ServerError>`, `sync`, `close` are produced by3.4c/d and joined under exclusive lease in3.5. Region commits and atomic standalone replacement are specified in04; no journal/global checkpoint.

Selection: dirty Revision>PersistedRevision or NeedsRewrite; exclude in-flight; sort unload first then dimension/X/Z; clone at selected revision once. Scheduler drains completions at next tick start, dispatches due retries then urgent then active autosave (cadence6000); autosave stays active until dirty/in-flight zero. Metadata has one in-flight latest target. Retry delay=min(1200,20*2^(attempt-1)) using checked cap-before-double, next tick saturating; queue-full preserves attempt. Sort due/region/retry-ID; only same-attempt/same-deadline cohorts may merge. Newer revision waits for old retry, then selects once.

Per-key ack: omitted submitted key with nil error is hard failure/retry; partial commits acknowledge only listed valid keys, retain remainder. Committed<snapshot or>current releases snapshot without ack and reports invalid completion. Equal snapshot monotonically advances persisted revision, clears only matching inflight. Committed>snapshot releases old inflight first; strictly below current may advance bounded persisted revision; equal current does not claim foreign content. Missing chunk cannot resurrect. Stale ack cannot clear newer inflight; unloading deletes only clean/noninflight. Backpressure uses dirty+inflight estimates (deliberate double count): enter>=512MiB, exit strictly below ceil(90%); limit100 stays90 exits89,101 stays91 exits90. This is separate from exact owned encoded bytes across queue/worker/completion/retry lanes, deduplicated by allocation-ticket identity.
