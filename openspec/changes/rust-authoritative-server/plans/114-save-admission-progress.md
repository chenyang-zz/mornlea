## Exact algorithm and interfaces

Private helper submit_prefix(&mut self, request: SaveRequest) -> Result<(SaveTicket, Vec<OwnedSnapshot>), SubmitSaveError>. First try the entire original request, preserving current batching when admissible. Only Capacity permits bounded prefix fallback. On refusal with length greater than1, split at floor(length/2), retain ordered suffix, retry the smaller prefix. New suffix precedes older held suffix. Stop at first admitted prefix; return ticket plus entire ordered untouched remainder. Single refusal or any non-Capacity error returns the complete original owners in original order. Every refusal remains last_error; successful partial admission does not hide its capacity diagnostic. No payload clone, encoding or I/O is added by fallback; at most logarithmic admission calls plus bounded O(n log n) Vec owner moves. Each original selection remains bounded by its authority/store lane contract; no larger production selection is introduced.

Fresh: tracked Fresh ticket covers only admitted prefix; return every tail owner through return_dirty exactly once. Count admitted snapshots only. Zero admission retains previous behavior.

Retry: dispatch_retry(&mut self, cohort: PendingRetry) -> (usize, bool), count admitted prefix and stop flag. Submit the existing request clone through submit_prefix. Admitted prefix keeps original cohort ID and tracked attempt+1. If a tail remains, split original retained cohort at admitted length, create a unique child ID with unchanged attempts/deadline, and keep that tail pending. Original prefix goes into dispatched; its identity/backoff policy does not change. Stop dispatch after partial admission/refusal. Non-Capacity refusal retains original cohort unchanged. Both due and final-flush retry loops call this helper. Fresh final flush must also call submit_prefix, track only admitted prefix, return tail exactly once, and count any admitted prefix as progress before its stall check. A wholly refused selection retains last_refusal. This prevents merged retry cohorts larger than available reservation capacity from stalling forever; no retry body recapture or attempt advancement for the tail.
