## Exact public and private contract

Existing CommitSettled variants remain compatible. Add a bounded output record, not retained state:

```rust
#[derive(Clone, Debug, PartialEq)]
pub struct CommitSettlement {
    pub outcome: CommitSettled,
    pub fulfilled: Option<CommitReservation>,
}
pub struct AuthoritativeMemoryFinalizer<'a> { owner: &'a mut MemoryOwner }
impl MemoryOwner {
    pub fn poll_commits_authoritative(&mut self, authority: &mut AuthorityState) -> Vec<CommitSettlement>;
    pub fn poll_reconciles_authoritative(&mut self, authority: &mut AuthorityState) -> Vec<ReconcileSettled>;
    pub fn poll_deletes_authoritative(&mut self, authority: &mut AuthorityState) -> Vec<DeleteSettled>;
    pub fn drain_authoritative(&mut self, authority: &mut AuthorityState, deadline: Deadline) -> Result<MemoryFinalizationReport, ServerError>;
    pub fn authoritative_finalizer(&mut self) -> AuthoritativeMemoryFinalizer<'_>;
}
```

The new private child accesses existing parent maps and helpers. Parent private poll/drain helpers take Option<&mut AuthorityState>; old methods use None, explicit authoritative methods use Some. No extra provider, retained proposal or aggregate map. Commit output carries the complete reservation (including line) exactly once after successful CAS so a later actual dialogue consumer can apply its separately owned issuer/effect. This node does not manufacture that issuer or accept dialogue publication. Legacy Applied payload remains unchanged for existing pure-provider consumers.

The object-safe MemoryFinalizer trait gains:

```rust
fn drain_authority(&mut self, authority: &mut AuthorityState, deadline: Deadline)
    -> Result<MemoryFinalizationReport, ServerError> {
    if authority.companion_persistence_enabled() {
        return Err(ServerError::InvalidInput { field: "memory_authority" });
    }
    self.drain(deadline)

```

Existing lifecycle doubles and pure remote finalizers keep their old operation only when the complete authoritative companion owner is disabled. Enabled ownership requires an override, so accidentally passing bare MemoryOwner refuses before remote drain. The explicit AuthoritativeMemoryFinalizer delegates pending/begin_attempt to its single MemoryOwner, overrides drain_authority to the authoritative drain, and refuses authority-less drain with InvalidInput{field:"memory_authority"}. Shutdown finalize_memory takes the existing &mut AuthorityState and calls drain_authority; both free shutdown and state-owned phase paths pass the same authority. This wrapper is the required configured caller, without an aliasing reference to authority inside itself. A borrowed authority and MemoryOwner remain separately owned, acyclic inputs. No global production fallback is introduced.
