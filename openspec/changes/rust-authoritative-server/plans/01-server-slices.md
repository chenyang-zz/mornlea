# F2 independently reviewable server slices

Read [00-execution.md](00-execution.md) and the F2 `design.md`/delta spec with every packet. `tasks.md` alone owns status. All paths below are relative to the repository root. `S` means `packages/engine/crates/mornlea_server/`; `R` means `packages/server/sim/`. These aliases expand to those exact directories, not a worker-selected location. Rust test command `CT(target, filter)` means `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_server --test target --locked filter -- --exact`; `CL(target)` is the same command with `-- --list`, with nonzero discovery required. Every node uses a first behavioral red, a real provider green, its cited Go characterization command, a scoped commit, and ledger evidence (SHA, fixture hash, discovered/executed count, limit/error observation). The controller owns the shared crate/root test entrypoints, `Cargo.lock`, registry, fixture manifest and ledger. A packet's `tests/.../<name>.rs` is a file-per-node module included by the controller's test entrypoint; workers never edit the entrypoint. Only the controller may change an accepted shared signature, after revising dependent packets.

## Dispatch and rollback rule

At most three disjoint worker modules run at once. A failed node is reverted only within its named exclusive files; the controller never broad-resets a dirty tree. Shared test entries, crate exports and fixture indexes are wired in one serial controller commit after each provider group. The controller commits each focused accepted node with one English `feat(server): ...` or `test(server): ...` subject and records the SHA. Rules 2.x can overlap with transport 3.2, store 3.4 and Agent 3.6 after 1.2; 3.1, 3.7, 3.8 and stage closure remain serial. A frozen contract conflict returns to 1.2 for an explicit revision and requalification of consumers.
