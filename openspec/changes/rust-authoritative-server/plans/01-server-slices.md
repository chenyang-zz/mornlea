Read [00-execution.md](00-execution.md), [02-core-seams.md](02-core-seams.md) and the F2 `design.md`/delta spec with every packet. `tasks.md` alone owns status. All paths below are relative to the repository root. `S` means `packages/engine/crates/mornlea_server/`; `R` means `packages/server/sim/`. Rust test command `CT(target, filter)` means `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_server --test target --locked filter`; `CL(target)` is the same command with `-- --list`, with nonzero discovery required. Only the controller may change an accepted shared signature, after revising dependent packets.
