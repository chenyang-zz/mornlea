# F2 independently reviewable server slices

Read [00-execution.md](00-execution.md), [02-core-seams.md](02-core-seams.md) and the F2 `design.md`/delta spec with every packet. `tasks.md` alone owns status. All paths below are relative to the repository root. `S` means `packages/engine/crates/mornlea_server/`; `R` means `packages/server/sim/`. These aliases expand to those exact directories, not a worker-selected location. Rust test command `CT(target, filter)` means `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_server --test target --locked filter`; `CL(target)` is the same command with `-- --list`, with nonzero discovery required. Every node uses a first behavioral red, a real provider green, its cited Go characterization command, a scoped commit, and ledger evidence (SHA, fixture hash, discovered/executed count, limit/error observation). The controller owns the shared crate/root test entrypoints, `Cargo.lock`, registry, fixture manifest and ledger. A packet's `tests/.../<name>.rs` is a file-per-node module included by the controller's test entrypoint; workers never edit the entrypoint. Only the controller may change an accepted shared signature, after revising dependent packets.
