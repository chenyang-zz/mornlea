Move actors, player_slots, runtimes, inventories, mining, projectiles, environment, sleeping, blocks, ready, drops, containers and container_chunks into the existing context fields. Add private carried `dirty_chunks:BTreeSet<ChunkKey>` to ResidentTickState and TickContext, plus a private loan marker recording whether the original sleep_record was Some and a sleep_record_touched flag. Move an existing sleep record; otherwise keep from_parts' canonical empty record. Context harness/from_fixture never owns a loan and keeps its existing detached behavior.

Add `pub(crate) fn TickContext::commit_carried(&mut self)` used only by production reducer and private production-context test helpers. It finalizes keys in dirty_chunks only, then returns all moved fields with mem::take to the same borrowed authority and clears the loan marker. For each dirty key with Ready ownership, call ReadyChunk::finish_tick with the latest DropState/ContainerState dirty predicates, clear only its drop dirty flag and finish only its ContainerState with that exact revision. No compact/body clone or scan of unrelated Ready values; one key appears once regardless of block/drop/container mutations. Clear the dirty set after successful finalization. Explicit successful commit preserves existing semantics of Some(sleep_record).

Implement Drop for TickContext: when a loan remains, move its current carried fields back without finalizing, clearing dirty flags or claiming successful tick publication. A read-only abandoned context restores exact values including original None sleep; a changed Sleep arm or set_sleep_record restores Some. Retain dirty_chunks with the carried maps so a later successful tick can finalize already accepted writes once. During unwinding ownership and work remain recoverable; Drop performs no provider work, encoding, I/O, panic-prone revision increment or new acknowledgement. This is ownership recovery, not global tick rollback. Existing reducer has no global transactional panic contract. A detached harness Drop never overwrites authority residents. Repeated commit_carried on a cleared loan is a no-op.

Both set_sleep_record and the RuleEffect::Sleep arm mark sleep_record_touched. Existing defensive compound rollback must restore that flag and dirty_chunks along with its existing snapshot fields until the separately frozen bounded journal replaces it. This node must preserve that rollback; do not remove or weaken its private fault test.

Add dirty keys at actual changed block writes only (replacement!=observed.block), and after successful stage/apply when pending drop/container copies have dirty=true. Counter-only drop changes never add a key. Ready preloads are clean and remove the corresponding pending key when replacing a fixture base. On successful staged mixed slot/block work all contributors converge on the one key. Existing no-op writes, failed preflight, revision exhaustion and compound rollback do not leave dirty index entries. The set's population is tied to accepted current effects rather than resident census; it cannot grow on idle ticks. ResidentTickState's derived Default/Clone includes this private set for explicit off-tick observers.

Keep resident_snapshot's detached clone/finalize behavior for public fixtures and explicit replay callers; document that production uses ownership handoff. Core step removes its resident_snapshot/commit_residents pair, collects events/counters/viewer leases as before, calls context.commit_carried, drops context, and retains existing schedules/viewer/publication ordering. Do not move authority session, metadata, outbox or scheduler ownership. Viewer clones stay bounded by live session/view caps.
