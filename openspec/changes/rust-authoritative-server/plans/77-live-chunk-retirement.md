## Exact authority operation and report

Public ChunkRetirementReport in state.rs derives Clone,Copy,Debug,Default,Eq,PartialEq, with pub retired:usize and pub first_error:Option<ServerError>. It preserves accepted-prefix progress when a later submission refuses; no separate retained history/index.

2. Loop at most min(max_chunks,8) candidates. If port.occupied()>=8, stop normally with current report, keeping all indexed bodies. Otherwise next_retirement None stops. Validate before any removal that exact ready exists with matching key/generation and drops/container_chunks owners exist; refusal Internal{invariant:"managed chunk ownership"} becomes first_error and stops with existing accepted-prefix count, no new detach. Keep the book record/index throughout admission.
3. Remove exactly those three map owners and blocks.take_chunk(key), wrap in accepted RetiredChunk::new; no Ready clone/capture/materialization/full-state snapshot or observation iteration. submit whole owner. Ok ->acquisition.retired(key,generation), increment report.retired. Err ->consume its contract-guaranteed SAME whole owner via into_parts, restore ready/drops/container_chunks and restore_chunk if Some; no member/dirty/revision/view/schedule mutation. Set report.first_error to exact rejection.error and stop. The accepted port's returned-owner obligation is trusted; no raw replacement/foreign-body injection or new public constructor. 4. Return report. Caller separately collects scalar disposal reports; this method must not wait/collect/drive disk/CPU or destroy the detached tree. Physical book removal acknowledges port ownership, not destructor completion.
