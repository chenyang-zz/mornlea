# P13 desktop launcher and release packets

Read this change's design/delta spec, accepted F2 S2/S3, F3 C1/G1 and P12 phase-2 evidence contract. `tasks.md` alone tracks status. The selected local mode is one supervised Rust server child over loopback TCP; Memory stays a F2/F3 parity surface. Existing default startup, previous release and world remain untouched during candidate qualification. The controller owns binary entrypoints, export manifest/presets, shared test entry, cross-target release script and ledger; workers own only named modules/tests. Every packet starts with a behavioral red and ends with real provider green, source/fixture/package hashes, nonzero test counts and rollback. One target's report never qualifies another.

**1.1 Release inventory and contract — controller.** Edit `testdata/runtime-migration/release/asset-manifest.json`, `testdata/runtime-migration/release/targets.json`, `ledger.md`. Enumerate exact Rust server/client/bridge, Godot, embedded Python extension/interpreter, asset/font/license, protocol/save/ABI, and previous-release backup identities. Manifest entries are `{logical_key,resource_kind,relative_path,sha256,license_id,targets:[os-arch],required}`; paths relative without `..`, duplicate key/path rejected. Exclude standalone Agent Python environment, Go pilot runtime, test/capture/comparison tools and non-target native libs from new product closure; keep previous release separately. Run `make godot-asset-check`, `make godot-project-check` and focused release audits; missing required hash/license blocks.

**1.2 Test seam — controller after 1.1.** Register prospective `packages/engine/crates/mornlea_client_core/tests/local_release_contract.rs` with file-per-node modules, `scripts/godot/desktop-release-check.sh --self-test`, and a typed fake process/lease interface in `src/local/contracts.rs`. The fake intentionally leaves a child alive after cancel for a behavioral red; validator must catch it. Run Rust `--test local_release_contract --locked -- --list`, target, script self-test and `go test ./packages/audit -run 'GodotPythonIsolation|GodotDesktopOnly|ReleaseUnit' -count=1`. Record accepted seam SHA.

**2.1 Process supervisor — worker owns `packages/engine/crates/mornlea_client_core/src/local/supervisor.rs`, `packages/engine/crates/mornlea_client_core/tests/local_release_contract/supervisor.rs`; consumes F2 server binary identity/lease and F3 TCP endpoint.** Spawn exactly one child with loopback-only bind and one named writable world lease; wait for authenticated readiness before client connect; on cancel/parent exit, request graceful flush then kill at the configured deadline and reap. No second world writer or orphan. Tests: normal startup/close, child exits before ready, bad identity, duplicate writer, cancel during login, timeout with forced reap and lost supervision. Run Rust supervisor filter plus `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_server --test persistence_failure --locked`.

**2.2 Typed launch progress — worker owns `apps/mornlea-godot/platform/desktop/lifecycle/launch_progress_feature.py`, `apps/mornlea-godot/tests/scripts/release_launch_check.py`; consumes F3 `session@1`/`lifecycle@1`.** Show pending/authenticated/failed/cancelled states from typed observations; cancel once, never create a second session or read process stdout as authority. Tests: startup, corrupt identity, child exit, double cancel and reset. Run `make godot-python-check`, `make godot-project-check`, `make godot-smoke`. No worker edits shared feature catalog.

**2.3 Asset/export resolver — worker owns `scripts/godot/release_manifest_check.py`, `apps/mornlea-godot/tests/scripts/release_manifest_check.py`; consumes 1.1 manifest.** Resolve every required dependency from package root, validate sha256/license/target and reject absolute/escaped path, system Python, wrong architecture, tooling inclusion, absent font/native library and duplicate manifest record. Test each invalid fixture plus valid relocatable package. Run `python3 scripts/godot/release_manifest_check.py --self-test`, `make godot-asset-check`, release audit filter. Do not edit export presets; controller wires exact qualified payload later.

**2.4 Release closure harness — controller after 2.1–2.3.** Exclusive `scripts/godot/desktop-release-check.sh`, `apps/mornlea-godot/export_presets.cfg`, launcher binary entrypoint and test entry wiring. `--target <macos|windows|linux> --run-dir <explicit>` rebuilds/identifies native artifacts, checks transitive package closure, runs editor/headless/export/open/100-cycle teardown and missing/corrupt resource/child-exit cases, and writes a strict `release.json` with source SHA, target architecture, runtime, package/asset hashes, protocol/save/ABI and rollback backup. `--self-test` uses temporary fixtures and cannot qualify a target. Run script self-test, full Rust local release target, `make godot-project-check`, audit release filters. The default launcher stays unchanged.
