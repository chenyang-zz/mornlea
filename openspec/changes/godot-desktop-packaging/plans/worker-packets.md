Read this change's design/delta spec, [local supervision contract](02-local-supervision.md), [Windows/Linux preparation packets](03-platform-preparation.md), accepted F2 S2/S3, F3 C1/G1 and P12 phase-2 evidence contract. `tasks.md` alone tracks status. Existing default startup, previous release and world remain untouched during candidate qualification.
