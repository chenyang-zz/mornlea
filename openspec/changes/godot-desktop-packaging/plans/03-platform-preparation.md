# P13 Windows and Linux package preparation

These six nodes are prospective, parallel platform providers after P13 1.1 freezes `targets.json`, pinned editor/Python inputs, target triples, archive digests and build tool versions. P13 1.2 registers their target fixture identities and shared release test seam. Each provider owns only the files below, starts with an invalid/missing artifact behavioral red, then proves a real artifact on the named actual host. A fixture or cross-build is never target qualification. P13 2.4 alone integrates the shared wrappers and export presets; workers never edit `scripts/godot/{godot,fetch,build-python-runtime,build-extension}.sh`, the release manifest, tracked project addons or the release checker. Every node records source/input/output hashes, host OS/arch, nonzero test count and a scoped commit; rollback removes only its generated cache/package output, never an existing release or world.

## Windows providers on an actual supported Windows host

**2.3b1 Pinned Godot editor — `scripts/godot/platform/windows/fetch-godot.ps1`, `scripts/godot/platform/windows/AGENTS.md`, `apps/mornlea-godot/tests/scripts/release_windows_godot_check.py`; after 1.1/1.2.** Read the frozen Windows target row and existing Darwin fetch behavior. Verify the pinned archive digest before extraction into an absolute cache outside the repository; normalize paths, reject archive traversal/symlink escape, wrong architecture/version and partial publication, and preserve an existing verified editor on failure. `-VerifyOnly` checks the installed editor without downloading; an actual-host test checks version, target architecture, digest and relocation. Run `pwsh -NoProfile -File scripts/godot/platform/windows/fetch-godot.ps1 -SelfTest`, `python3 apps/mornlea-godot/tests/scripts/release_windows_godot_check.py`, then `-VerifyOnly` against the actual pinned editor. Red: corrupt archive and wrong version cannot replace cache. Exclude Python and native extension.

**2.3b2 Embedded Python payload — `scripts/godot/platform/windows/build-python.ps1`, `apps/mornlea-godot/tests/scripts/release_windows_python_check.py`; after 1.1/1.2.** Resolve only the frozen Py4Godot fork/interpreter/build inputs; build or materialize the target Windows embedded Python payload in a temporary external cache, verify every native wheel/library hash and ABI, then atomically publish the complete relocatable payload. Reject a system Python dependency, missing DLL, wrong architecture/ABI, incomplete extraction and a stale prior payload; leave the previous verified cache intact on failure. Run PowerShell `-SelfTest`, the named Python test and `-VerifyOnly` plus an actual embedded interpreter/import probe on Windows. Red: package with an omitted DLL fails closure. Exclude Agent Python and tracked project addon writes.

**2.3b3 Native Rust/GDExtension payload — `scripts/godot/platform/windows/build-extension.ps1`, `apps/mornlea-godot/tests/scripts/release_windows_extension_check.py`; after 1.1/1.2 and accepted F3/G1 SHA.** Build the frozen Windows Rust target on Windows with the accepted bridge ABI, verify host triple, exported symbols and dependent DLL closure, and stage the DLL under its target package path with SHA. Reject wrong ABI, missing dependency, debug/release mismatch and stale output. Run PowerShell `-SelfTest`, the named Python test and actual-host `-VerifyOnly`/loader probe; record the compiled source SHA. Red: mismatched ABI or absent DLL fails before package publication. Exclude shared Rust ABI declarations and export presets.

## Linux providers on an actual supported Linux host

**2.3c1 Pinned Godot editor — `scripts/godot/platform/linux/fetch-godot.sh`, `scripts/godot/platform/linux/AGENTS.md`, `apps/mornlea-godot/tests/scripts/release_linux_godot_check.py`; after 1.1/1.2.** Use the frozen Linux editor archive/architecture row, verify digest before extracting to an absolute external cache, reject traversal/symlink escape, wrong version/ELF architecture and partial publication, and retain a verified previous cache on failure. `--verify-only` performs no download. Run `bash scripts/godot/platform/linux/fetch-godot.sh --self-test`, the named Python test and actual-host `--verify-only`/version probe. Red: corrupt archive and wrong ELF class fail. Exclude Python and native extension.

**2.3c2 Embedded Python payload — `scripts/godot/platform/linux/build-python.sh`, `apps/mornlea-godot/tests/scripts/release_linux_python_check.py`; after 1.1/1.2.** Build or materialize only the frozen target Py4Godot/interpreter payload, verify hashes, SONAME/loader closure and ABI, and atomically publish an external relocatable cache. Reject system Python at runtime, missing `.so`, wrong architecture, unsupported libc baseline, incomplete copy and stale payload without replacing a previously verified cache. Run `bash scripts/godot/platform/linux/build-python.sh --self-test`, the named Python test and actual-host `--verify-only`/embedded import probe. Red: absent dependent `.so` fails closure. Exclude Agent Python and tracked addons.

**2.3c3 Native Rust/GDExtension payload — `scripts/godot/platform/linux/build-extension.sh`, `apps/mornlea-godot/tests/scripts/release_linux_extension_check.py`; after 1.1/1.2 and accepted F3/G1 SHA.** Build the frozen Linux Rust target on Linux, verify source/host triple, bridge ABI, exported symbols, ELF loader and shared-library closure, then stage the `.so` with SHA under its target package path. Reject wrong ABI, missing dependency, incompatible libc and stale output. Run `bash scripts/godot/platform/linux/build-extension.sh --self-test`, the named Python test and actual-host `--verify-only`/loader probe. Red: missing dependency prevents package publication. Exclude shared ABI declarations and export presets.

## Serial integration and target evidence

P13 2.4 follows all six providers plus 2.1a–2.3. The controller exclusively routes `scripts/godot/{godot,fetch,build-python-runtime,build-extension}.sh` by explicit target and actual host, preserving the Darwin path, and wires the accepted target payloads into `desktop-release-check.sh` and export presets. It rejects a host/target mismatch before invoking any platform provider. P13 3.1–3.3 independently run real package/loader/embedded Python/child teardown/relocation tests on their corresponding hosts and bind the resulting artifact hashes to the release report. Missing native toolchain or pinned input leaves that target pending; no self-test or another host's report substitutes.
