# Numerical closure: execution contract and interface landing

**Goal:** expose typed numerical contracts before any provider is implemented, then let disjoint providers and consumer test doubles advance from the same accepted interface SHA. **Architecture:** Rust owns the final server/client numerical core; Godot's embedded Python is presentation only. The current Go runtime and engine ABI v11 remain compatibility seams during this change. **Spec:** [delta](../specs/rust-runtime-foundation/spec.md), [design](../design.md), [field and algorithm contract](../worker-briefs.md#node-5-1). `tasks.md` alone records status.

`ENGINE` below means `packages/engine/crates/mornlea_engine`. File paths beginning `src/` or `tests/` are relative to `ENGINE`. Every node starts from its recorded predecessor SHA, reads the nearest `AGENTS.md`, runs `git status --short`, writes the named failing test before behavior, records the actual red (a missing symbol is a compile red), runs the focused green gate and nonzero test discovery, receives independent review, updates `ledger.md`, and makes one scoped commit. A worker must report a contract conflict with source line and observed result; it must not silently change a shared type or another lane. Go case exports use an external create-exclusive `RUNTIME_ORACLE_EXPORT_DIR`; tracked corpus assets and `contracts.json` are owned only by 3.12. Inputs and output/scratch canaries are immutable until successful publication. `KernelError` capacities count typed elements; adapters alone translate to ABI byte or slot units.

The interface SHA is the sole prerequisite for provider nodes 2.1–2.10 and 2.12. Nodes 2.11 and 2.13 are serial continuations of their own lane. The controller serializes every `src/ffi.rs` change; a provider can start while unrelated adapters are in progress, but its adapter starts only after that provider passes. Shared contract, `src/lib.rs`, the test roots and corpus registry are never family-worker editable. A task containing a read-only file may inspect it but cannot stage it. Each rollback removes only its owned source/test/temporary evidence, unless a dependent adapter has already landed, in which case the controller reverts that adapter and its matching corpus fragment together.

## File ownership before dispatch

| Owner | Exact files and responsibility |
| --- | --- |
| Interface controller, 1.2 | `src/native/contracts/{mod,collision,physics,raycast,world,fluid,mesh,pathfind}.rs` owns types, errors, trait signatures and shared validated constructors; `src/native/mod.rs`, `src/lib.rs` export the fixed tree; `src/worldgen.rs` owns the shared tree visitor; `src/native/AGENTS.md` and `ENGINE/AGENTS.md` describe the boundary; `tests/native_contract.rs` and `tests/numerical_migration.rs` register topic modules once. |
| Family provider | Only the exact source, topic tests and Go producer named in its [file packet](01-providers.md). No family edits contracts, root registration, ABI, manifest or another family file. |
| Adapter controller | `src/ffi.rs` plus the exact family migration test in [adapter packets](02-adapters.md); one accepted adapter commit before another `ffi.rs` edit. |
| Corpus controller | Registry, loader, test-only raw Go producer, manifest, assets and guides in [closure packets](03-closure.md), after reviewed family fragments. |

The interface landing assigns each contract file one stable subject, so a later provider has no reason to edit a shared declaration:

| Contract file | Types and consumers |
| --- | --- |
| `src/native/contracts/mod.rs` | `KernelError`, shared typed-element capacity rules and reexports; all ten legacy-family providers consume it. |
| `src/native/contracts/collision.rs` | `Aabb`, `CollisionCell`, `CollisionGrid`, request/result and `CollisionOp`; physics reads the exact same grid. |
| `src/native/contracts/physics.rs` | State, controls, tuning, sweep, result and `PhysicsOp`; ABI adapter 3.3 converts raw fields only at the boundary. |
| `src/native/contracts/raycast.rs` | Ray, face/record/batch and opaque cursor declarations with `RaycastOp`; continuation state is not public wire data. |
| `src/native/contracts/world.rs` | Fifteen-field `Materials`, validated `WorldgenParams`, chunk/probe/tree/LOD types and four operation traits; `as_legacy()` is the one crate-private sampler bridge. |
| `src/native/contracts/fluid.rs` | Evaluation slot/write types, rescan view/range/summary and both operation traits; native interior and legacy outer admission remain distinct. |
| `src/native/contracts/mesh.rs` | Registry/view/quad/scratch declarations, model enum and `MeshOp`; light and geometry nodes complete their own constructors/methods without redefining fields. |
| `src/native/contracts/pathfind.rs` | Grid/cell/revision/table/scratch/result declarations, `PathError` and `PathfindOp`; grid and search are sequential owners of their implementation file. |

Review focus carried into specific tests: a used NaN cell must reject while an unused NaN slot remains accepted (1.2/2.1); the shared world parameter conversion must preserve all 15 material IDs and 512 permutation bytes (1.2); a visitor refusal must not publish a partial tree (1.2/2.6); a later output overflow must leave earlier bytes untouched (2.11/3.11); a valid raw metadata pointer aliased to input/output/scratch must not be cleared (3.1).

## Node 1.1 — freeze the actual numerical starting point

**Prerequisite:** accepted domain-event, protocol, region and storage archive ledgers. **Editable:** `openspec/changes/rust-native-numerical-closure/ledger.md` only. **Read-only:** `src/ffi.rs`, `src/lib.rs`, `packages/shared/nativeabi/native.go`, `packages/tools/cmd/runtime-oracle/inventory.go`, `testdata/runtime-migration/contracts.json`, predecessor ledgers and current engine source. **Produces:** a ledger row with four accepted predecessor SHAs, engine source SHA and ABI v11, and all eleven route IDs/version/current case counts; it is the evidence gate for 1.2, not code or corpus acceptance.

1. Read the four accepted ledger SHAs and resolve each to a commit. Inspect all ten exported numerical symbols in `src/ffi.rs` and `kernel.pathfind` in the manifest; record each family ID, version, operation and current `cases` count. Calculate SHA-256 for every currently listed numerical `sources[]` path and record the engine `ffi.rs` and `lib.rs` source identity. A missing source or changed ABI/version blocks the interface landing pending a design revision.
2. Run `go test ./packages/tools/cmd/runtime-oracle -run '^TestContractInventory' -count=1` and `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_engine --locked -- --list`. The inventory may pass while all eleven kernel routes still have zero accepted cases; record actual discovery and distinguish zero coverage from test failure.
3. Append the evidence and the exact command/exit/SHA to the ledger. Do not alter the manifest or claim a provider exists. **Commit:** `docs(openspec): pin numerical migration baseline`. **Rollback:** this ledger entry only.

## Node 1.2 — publish the compile-ready interface

**Prerequisite:** accepted 1.1 SHA. **Editable source:** `src/native/contracts/mod.rs`, `collision.rs`, `physics.rs`, `raycast.rs`, `world.rs`, `fluid.rs`, `mesh.rs`, `pathfind.rs`; `src/native/mod.rs`; `src/lib.rs`; `src/worldgen.rs`; `src/native/AGENTS.md`; `ENGINE/AGENTS.md`. **Editable test roots:** `tests/native_contract.rs`, `tests/native_contract/contracts.rs`, `tests/numerical_migration.rs`. **Create empty, compiling provider modules:** `src/native/{collision,physics,raycast,worldgen,world_probe,tree,lod,fluid_eval,fluid_rescan,mesh,pathfind}.rs`. **Create empty, compiling topic children:** `tests/native_contract/{collision,physics,raycast,worldgen_chunk,worldgen_probe,tree_blocks,lod,fluid_eval,fluid_rescan,mesh_view,mesh,publication}.rs` and `tests/numerical_migration/{collision,physics,raycast,worldgen_chunk,worldgen_probe,tree_blocks,lod,fluid_eval,fluid_rescan,mesh,path_grid,path_search}.rs`. The roots register each child with explicit `#[path = "..."] mod ...;`; later workers edit their topic child, not a root. **Read-only:** `src/ffi.rs`, Go bridges, manifest and unrelated engine crates.

**Exact interface:** the eleven object-safe traits and signatures in [brief 5.1](../worker-briefs.md#node-5-1); `KernelError` variants and typed-element `needed/available`; private validated view fields; public request/result types from 5.2–5.13. The shared constructors are executable now: `CollisionCell::try_new(loaded, boxes, used)` checks `used<=8` and finite components of used boxes only; `CollisionGrid::try_new(origin, dimensions, cells)` checks positive dimensions, checked product `<=4096`, exact cell count and representable far endpoint; `WorldgenParams::try_new(seed, materials, perm)` accepts only the documented water==air duplicate among 15 IDs and any 512 permutation bytes. `WorldgenParams::as_legacy()` copies all fields by value. Family-private scratch/cursor constructors can be completed by their provider owner; there is no production placeholder operation returning a fake result.

**Test-first steps:**

1. In `tests/native_contract/contracts.rs`, write a distinct deterministic struct implementing each trait; pass `&dyn FluidEvalOp` into a generic caller and assert one `Ok(1)` and one `Err(KernelError::InvalidInput)`. Build compile-only calls for every borrowed request/scratch signature. The initial red is an unresolved `native::contracts` import, not a fabricated numerical mismatch.
2. Add executable constructor cases: `[16,16,16]`/4096 cells accepted; zero dimension, 4097 cells, overflowing far endpoint and a used NaN reject; an unused-slot NaN succeeds. Test 15 distinct material IDs, water==air, another duplicate rejection, all-zero permutation, and field-for-field equality after `as_legacy()`.
3. In `src/worldgen.rs`, first test ordinary, trunk-height 5/6/7 and fluffy tree records from old `tree_blocks` against a collector passed to `visit_tree_blocks`. Refusing the second emission returns `None` without a public partial result. Extract `visit_tree_blocks(request, emit)` preserving dy/dz/dx order and its 128-record invariant; make the Vec-returning legacy helper call the visitor.
4. Declare all fixed types, getters, signatures, modules and guides. The guide states purpose, import direction, entry points, scratch lifecycle, ABI compatibility and focused gates. Do not implement any real numerical provider or touch `ffi.rs`.

**Expected green:** `native_contract -- --list` discovers contract tests; their execution checks actual doubles and constructors; the tree visitor parity/refusal tests run. **Validate:** `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_engine --test native_contract --locked -- --list`; the same command without `-- --list`; `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_engine --lib --locked tree_blocks`; `rustup run 1.97.1 cargo clippy --manifest-path packages/engine/Cargo.toml -p mornlea_engine --all-targets --locked -- -D warnings`. **Commit:** `feat(engine): freeze native numerical contracts`. **Rollback:** revert this landing only before a dependent provider starts; after that, revise the central contract and consumers as a coordinated change.
