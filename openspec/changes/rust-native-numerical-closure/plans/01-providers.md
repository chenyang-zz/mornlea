# Numerical provider file packets

**Goal:** turn the frozen [interface](00-foundation.md#node-1-2) into independently testable Rust numerical providers. **Architecture:** each provider validates typed input, calls the existing crate-private algorithm through immutable views, and returns owned/staged output. **Tech stack:** Rust 1.97.1 and test-only Go oracle producers. **Spec:** [delta](../specs/rust-runtime-foundation/spec.md), [design](../design.md), [exact fields, algorithms and limits](../worker-briefs.md#node-5-2). Status is tracked only in `tasks.md`.

All `src/` and `tests/` paths are relative to `packages/engine/crates/mornlea_engine`; Go paths are repository-relative. Every node edits exactly its listed files, first adds its named native test and observes a real red, then implements the smallest shared-core route, runs `native_contract` or `numerical_migration` with `-- --list` to prove nonzero discovery and runs the exact focused commands below. A missing provider is a compile red; after it compiles, compare actual field bits, record order, category and canary bytes. Go producer tests call existing `nativeabi`/Go code, export drafts only to external `RUNTIME_ORACLE_EXPORT_DIR`, and never edit the tracked manifest. `src/native/contracts/**`, `src/lib.rs`, `src/ffi.rs`, test roots and `contracts.json` are read-only for every provider. Review and commit each verified node independently; its rollback removes the provider/test/producer together, while an already landed adapter is reverted by the controller. Do not call the ABI from new native Rust.

## Node 2.1 — collision

**Prerequisite/interface:** 1.2; `CollisionOp::resolve(&CollisionRequest)->Result<CollisionResult,KernelError>` and the already validated `CollisionGrid`. **Files:** `src/collision.rs` exposes its existing Y→X→Z, ground-probe and step-selection core to a crate-private `CollisionCells` read view; `src/native/collision.rs` builds a borrowed typed-cell view and validates finite request and required swept coverage; `tests/native_contract/collision.rs` owns the direct provider tests; `tests/numerical_migration/collision.rs` owns field-by-field ABI parity/canaries; `packages/tools/cmd/runtime-oracle/kernel_collision_test.go` produces source-bound valid/error observations. **Read-only:** `src/step.rs`, contracts, `src/ffi.rs` and corpus registry.

Write `collision_floor_wall_unknown_bits` and `collision_swept_coverage` first. A loaded floor/wall, unloaded neighbor and negative-zero displacement compare all three `f32::to_bits()` and five flags; missing one swept cell gives `DisplacementOutOfBounds`, a covering superset succeeds. Test 4096/4097 cells, used versus unused NaN, zero dimension, endpoint overflow, accepted negative step and an alternate step that must not leak `hit_unknown`. Validate before reading, borrow native cells without re-encoding, and keep the old core's float order. Run `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_engine --test native_contract --locked collision`, `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_engine --lib --locked collision`, and `go test ./packages/tools/cmd/runtime-oracle -run '^TestKernelCollision' -count=1` (Rust commands use the pinned toolchain). **Commit:** `feat(engine): expose validated native collision`.
