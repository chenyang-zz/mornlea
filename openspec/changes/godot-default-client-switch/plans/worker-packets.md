# P14 product cutover and bounded retirement packets

Read this change's design and both delta specs, the [target interface map](../../../../docs/runtime-interface-architecture.md), and accepted F1–F3/P8–P13 ledgers. `tasks.md` alone tracks status. This plan is prospective: none of the runtime cutover, two release cycles or human approval has happened. The controller owns shared Makefile/CI/audit, feature/release manifests, default entry, cutover script and ledger. Worker packets use exclusive files. Every new test must fail behaviorally before the implementation, discover nonzero tests, then pass against the real package. Record exact SHA, source/package/runtime hashes, platform/case coverage, hard errors and full previous-release rollback. Planning validation or a mock self-test is never a release cycle.

## Gate and diagnostic contracts

**1.1 Full prerequisite inventory — controller.** Edit `openspec/changes/godot-default-client-switch/ledger.md` and `testdata/runtime-migration/release/cutover-inventory.json`. Bind accepted F1–F3 and P8–P13 implementation SHAs, per-family F3/G1 descriptors, per-target P13 reports, P12 canonical/approved owner cases, F2 protocol/save identities and whole previous-release backup. Enumerate every executable/loading path and transitive native dependency, including pilot Go core ABI and independent `mornlea_client` renderer ABI v19 consumers. A missing required feature/platform/case or mixed producer makes gate fail. Run `openspec validate --all --strict --no-interactive`, `cargo metadata` and audit release/architecture filters; these inspect artifacts but do not substitute for accepted ledgers.

**1.2 Cutover test seam — controller after 1.1.** Create prospective `packages/engine/crates/mornlea_client_core/tests/product_cutover.rs` with file-per-node modules and `scripts/godot/product-cutover-check.sh --self-test`. Pin strict cycle report schema `{release_id,source_sha,package_sha256,manifest_sha256,protocol_version,save_schema,bridge_id,platform_reports,feature_cases,visual_owner_registry_sha256,hard_error_report,previous_release_sha256,backup_sha256,restore_result}`. All required fields are nonempty; `feature_cases` covers the accepted P8–P11 inventory, platform reports cover macOS/Windows/Linux and `restore_result` is `pass`. Two cycles require different release IDs, separately built package hashes and distinct recorded build/test run IDs, with cycle 2 built as a subsequent release candidate; copying reports is rejected. Test missing P8, one cycle, duplicated package/run, mixed runtime and absent backup under a permissive fake for behavioral reds. Run Rust target `-- --list`, full target and script self-test.

**1.3 Audit replacement tests — controller after 1.2; exclusive `packages/audit/godot_entrypoints_test.go`, `godot_project_closure_test.go`, `godot_release_unit_test.go` and associated fixtures.** Add red-first checks that product mode has Rust server/client bridge and embedded Python, no Go session/server runtime or tooling CLI, one world writer, native diagnostics and exact platform closure; pilot mode still satisfies its pre-cutover optional constraints. Keep unrelated authority, isolation and visual-owner checks. Run `go test ./packages/audit -run 'Godot|Architecture|ReleaseUnit' -count=1`. Do not delete tests or set exemption variables to make a new entry green.

**2.1 Native setup diagnostics — worker owns new `apps/mornlea-godot/app/host/native_setup_diagnostics.py`, `apps/mornlea-godot/tests/scripts/native_setup_check.py` and `packages/engine/crates/mornlea_client_core/tests/product_cutover/diagnostics.rs`; after P13 launcher accepted.** Before Python feature import or session creation, native launcher verifies required Rust/bridge/Python artifacts and hashes, target and export/source preparation. Return a typed actionable missing/corrupt/unprepared reason; never launch a mixed Go/Rust session. Test unprepared source tree, prepared source, exported package, missing extension, wrong architecture, corrupt bridge and repeated teardown. Run Rust diagnostics filter, `make godot-project-check`, `make godot-smoke`. Controller owns project main-scene wiring later; Bootstrap remains meanwhile.

**2.2 Transitive closure checker — worker owns `scripts/godot/release_closure_check.py`, `packages/engine/crates/mornlea_client_core/tests/product_cutover/closure.rs`; read P13 release manifest.** Walk actual executable/native dependency graph and selected product package, reject pilot Go shared library, Go server process, old renderer ABI consumer, comparison/capture tooling, system Python and non-target libraries; allow specifically inventoried offline tools outside product package and complete previous release. Test direct and transitive Go edge, two distinct ABI surfaces, symlink escape, missing required dependency, partial restore and valid product closure. Run Rust closure filter and `scripts/godot/product-cutover-check.sh --self-test`. This worker does not delete source packages.

**2.3 Release cycle 1 — controller after 1.1–2.2 and P13 target qualification.** Build a complete candidate from a recorded SHA; run every real P8–P13 semantic, visual, rollback, local/remote, platform, and hard-error gate. Write `build/release-evidence/cycle-1` with actual signed/checksummed package and case reports, then restore the complete previous release against a compatibility-checked backup. Run `scripts/godot/product-cutover-check.sh --run-dir build/release-evidence/cycle-1 --strict`, `make dev-check`, `make test-race`. No default switch; any missing case or restore failure keeps node open.

**2.4 Release cycle 2 — controller, only after 2.3.** Build a subsequent distinct candidate and repeat the entire gate, with new release/build/run/package identities, writing `build/release-evidence/cycle-2`. Run `scripts/godot/product-cutover-check.sh --run-dir build/release-evidence/cycle-2 --previous-cycle build/release-evidence/cycle-1 --strict`, `make dev-check`, `make test-race`. Duplicate package/run or borrowed target/visual report fails. No default switch yet.

## Approval, switch and separate retirement

**3.1 Approved default switch — controller after both cycles and explicit cutover approval recorded in ledger.** Exclusive `Makefile`, `.github/workflows/godot.yml`, `apps/mornlea-godot/project.godot`, `app/host/app_root.tscn`, entry scripts, audit replacement wiring and relevant guides. Test default open, remote/local, missing runtime diagnostics, mixed-runtime refusal, rollback, six-module audit and all release cases. Run cutover strict checker, `go test ./packages/audit -count=1`, `make dev-check`, `make test-race`. This is an externally consequential later action; a plan checkbox does not authorize it by itself.

**3.2 Bootstrap/pilot product-closure retirement — controller after 3.1; exclusive `apps/mornlea-godot/app/bootstrap/`, pilot shared-library selection in `packages/engine/crates/mornlea_godot/src/client_core.rs`, export manifest and corresponding tests.** Remove migration Bootstrap only after 2.1 diagnostics cover prepared/unprepared/exported states. Run `make godot-project-check`, `make godot-python-check`, Rust `product_cutover`, strict checker. Source deletion is not implied.

**3.3 Old renderer ABI v19 consumer retirement — controller, separate node after 3.2.** Inventory all `packages/engine/crates/mornlea_client` FFI consumers and source/export references; edit only the verified consumer list and workspace/build registration required to remove the selected product dependency. **3.4 Go real-time source consumer retirement — controller, separate node after 3.2/3.3.** Inventory `packages/client/cmd/mornlea-godot-core`, Go server/client commands and scripts; remove only verified unused product launch/build edges, keep approved offline tools and prior release. Record consumer graph, scoped commit and rollback.

**4.1 Final ledger and architecture reconciliation — controller.** Re-enumerate D0–T1 and supported feature/platform/visual cases, bind both release cycles and per-node retirement evidence, update guides and skill only for verified cross-task rules; missing evidence blocks closure. **4.2 Final gate — controller:** `rustup run 1.97.1 cargo fmt --manifest-path packages/engine/Cargo.toml --all --check`, `make godot-python-check`, `make rust-check`, `make dev-check`, `make test-race`, `go test ./packages/audit -count=1`, `openspec validate --all --strict --no-interactive` on final SHA, then verify complete previous-release restore.
